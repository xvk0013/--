# 独立三目标生成分支

三目标数据作为固定0／1／2目标数据的增量扩展，单独写入 `datasets/shipsear_pf_mb_rv_triple_0db_v1`。原始4473条数据、源组件、录音划分和原排列索引保持不变。模型适配尚未开始。

## 使用

在数据生成器目录运行：

```powershell
# 只预览三目标样本计划，不写入数据
.\RUN_GENERATE.ps1 -TripleOnly -PlanOnly

# 只生成三目标，不进入原数据生成或MATLAB组件重建流程
.\RUN_GENERATE.ps1 -TripleOnly
```

Python等价入口：

```powershell
python -B -X utf8 generator/generate.py --triple-only
```

`config.json` 中的 `triple.enabled` 默认是 `false`，因此不加参数时仍走原来的数据入口。也可将其设为 `true`，此时默认命令只生成三目标。`-TripleOnly`可直接启用本次运行，无需修改默认开关。它不能与 `-RebuildComponents` 同用。

已经生成完整输出时，再运行会直接保留现有文件。改变三目标参数后，应设置新的 `triple.output_directory`；不会静默覆盖旧版本，也不提供强制重写原数据的入口。

## 首版配置

|集合|原始0／1／2目标|新增三目标|未来按集合拼接后|
|---|---:|---:|---:|
|Train|2880|576|3456|
|Val|716|144|860|
|Test|877|176|1053|
|合计|4473|896|5369|

`triple.samples_per_split=null`时，新增样本量取原集合双目标样本数的三分之一，即约等于一个双目标组合的规模。也可设为 `{"Train":576,"Val":144,"Test":176}`，独立控制数量。这里不强制新数据的全局任务比例，既有0／1／2目标比例不调整。

每条样本按固定顺序取PF、MB、RV各一份已有Bellhop组件，只从当前集合的已接受索引来源中选取。组件循环打散，重复三元组使用不重复候选补位；固定种子42可复现计划。现有源池较小的类别仍会复用片段，分集合的录音归属保持不变，不进行跨集合取源或重排。

三目标统一标签为 `PF+MB+RV`，`label_index=7`、`count=3`、多标签向量为 `[1,1,1]`。原标签0至6不变。当前只有三种船型，因此三目标对应一种集合；后续主要评价三目标检出与数量混淆，不将其当成多种三目标组合的辨别实验。

## 三路混合

每份组件为5秒、16 kHz单声道。各路先按 `relative_level_db` 调整RMS，再施加包络并叠加，最后通过公共增益将混合波形归一化至RMS 0.05。首版相对电平为 `[0,0,0]`，不额外加入噪声。

这里的0 dB表示施加包络前各源成对等功率，和加噪实验的SNR不同。按另外两路功率之和作为干扰功率计算，每一路对应约−3.01 dB；不是每一路相对于其余两路合计仍为0 dB。索引中的 `nominal_sir_db` 对三目标留空，三路相对电平与实际增益分别记录，避免继承双目标字段而混淆定义。

|上下文|三目标包络含义|首版比例|
|---|---|---:|
|C0|三路全程叠加|约50%|
|C1|一侧边缘由一路占优，其余两路降至弱幅度；另一侧及中部三路完整叠加|约25%|
|C2|首尾分别由不同源占优，其余源在相应边缘减弱；中部三路完整叠加|约25%|

占优区仍为随机0.8–1.2秒，过渡0.2–0.3秒，弱路幅度0.1；Train/Val/Test使用同一参数分布。三路不是被裁断后拼接，所有源在占优区也保留弱幅度。上述C1/C2是本次明确规定的三路扩展，并非复制原双目标包络索引。

首版各集合C0/C1/C2数量分别为Train 288/144/144、Val 72/36/36、Test 88/44/44。比例按整数分配，没有要求精确相等的断言。

## 文件与读取

- `generator/generate_triple.py`：三目标取源、三路包络、混合与独立写入。
- `datasets/shipsear_pf_mb_rv_triple_0db_v1/DATA_INDEX.csv`：唯一三目标排列索引，含三份源组件、来源录音、包络、电平及混合增益。
- `data/{Train,Val,Test}/audio.npy`：float32波形数组，每条80000点。
- `CONFIG.json`：本次实际配置；`SUMMARY.json`：数量和上下文分布。

默认 `triple.export_wavs=false`，只保存数组，避免重复存储。需要WAV时可在新版本配置中启用。源组件路径相对于数据生成器根目录。

现有加载器可以直接读取新增数据：

```python
import sys
from pathlib import Path
root = Path(r'D:\LSJ\Code\UART\shipsear\ShipsEar_DataGen_Final_0dB')
sys.path.insert(0, str(root / 'generator'))
from dataset import MixedDataset
data = MixedDataset(root / 'datasets/shipsear_pf_mb_rv_triple_0db_v1', 'Train')
audio, targets, labels, counts = data.batch([0, 1, 2])
```

后续训练可以将原集合与对应三目标集合按读取视图组合，不需要重写原数组。旧七类模型尚不支持标签7与数量3，需要下一阶段适配数量头、类别输出和公共成员接口；本次不自动启动训练。

运行时只做取源归属、输出路径、必要配置及音频格式/有效性的检查；没有新增文件哈希扫描或全量质量审计。开发测试检查混合计算、跨集合保护、重复运行及加载器兼容，不作为每次生成前的重型流程。
