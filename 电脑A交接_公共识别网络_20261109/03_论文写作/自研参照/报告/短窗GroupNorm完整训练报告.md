# 短窗GroupNorm完整训练报告

ShortLocal-GN 把 30 ms log-Mel 短窗 CNN 中的三处 BatchNorm2d 替换为四组 GroupNorm。两版均从种子 13 的模型构造初值训练。已逐值核对可学习参数初值，参数量均为 2,721,537。

训练复用同一 ShipsEar 录音划分和原始／10／5／0／−5／−10 dB 的 50／10／10／10／10／10 采样协议。共同的 40 轮中，每轮六档采样计数一致。沿用综合 Val 规则选择轮次，封存后评价 Test。两版的 Val 和 Test 逐条预测按样本编号、真实类别和交汇条件配对。

| 模型 | 实际训练轮数 | Val 选中轮次 | Val 单双均衡分 | Val 综合均值 | Test 综合均值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| ShortLocal | 42 | 32 | 66.51% | 64.14% | 76.09% |
| ShortLocal-GN | 40 | 29 | 64.51% | 61.73% | 75.56% |

复现命令为 `python research/shipsear_finalization_20261103/train_formal.py --short-record-normalization`。首批训练、保存恢复后的下一次参数更新均已核验。[结构检查](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/runs/short_local_GN_structure_check.json) · [训练检查](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/runs/short_local_GN_smoke.json)

## Val 背景逐录音

每格为 ShortLocal → ShortLocal-GN 的正确切片数。各档使用同一组切片的对应噪声视图。

| 条件 | 83 号（36 条） | 85 号（25 条） | 91 号（10 条） | 总计（71 条） |
| --- | ---: | ---: | ---: | ---: |
| 原始 | 36 → 36 | 25 → 20 | 0 → 0 | 61 → 56 |
| 10 dB | 36 → 36 | 25 → 18 | 0 → 0 | 61 → 54 |
| 5 dB | 36 → 35 | 23 → 20 | 0 → 0 | 59 → 55 |
| 0 dB | 35 → 35 | 22 → 22 | 0 → 0 | 57 → 57 |
| −5 dB | 35 → 35 | 23 → 24 | 0 → 0 | 58 → 59 |
| −10 dB | 32 → 28 | 23 → 25 | 0 → 0 | 55 → 53 |

六档 Val 背景均值由 82.39% 降至 78.40%。91 号在两版中均为六档全错。原始和 10 dB 的新增背景错误集中在 85 号，分别多错 5 条和 7 条。

## Test 背景与船目标误判

| 条件 | 背景判成船 | 船判成背景 |
| --- | ---: | ---: |
| 原始 | 0 → 0 | 0 → 0 |
| 10 dB | 0 → 0 | 1 → 1 |
| 5 dB | 1 → 0 | 1 → 1 |
| 0 dB | 3 → 0 | 0 → 1 |
| −5 dB | 0 → 0 | 1 → 2 |
| −10 dB | 0 → 0 | 18 → 16 |

GN 找回了 84 号在 5 dB 的 1 条和 0 dB 的 3 条背景错例，使 Test 两条背景录音在六档均达到 87/87。−10 dB 的 Single 为 65.65%，Double 由 49.24% 降至 46.21%，对应综合 ACC 由 59.18% 降至 57.35%。

GN 在原始档达到 85.18% 综合 ACC，Test 的 Single 和 Double 均随噪声加重逐档下降。考虑 Val 背景与综合表现以及 −5／−10 dB 的 Double 损失，ShortLocal 继续作为主线。GN 保留为测试背景全对、原始档超过 85% 的候选。本轮结果来自一个训练种子和这一套录音划分。
