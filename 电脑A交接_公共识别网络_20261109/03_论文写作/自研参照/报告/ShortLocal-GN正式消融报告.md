## 等参数乘积与加法对照

下表为 GN-ADD → 完整 GN 的同样本变化，正确 Double 要求两种船型的组合完全命中。

| Test 条件 | 正确 Single | 正确 Double | Double → Single | 数量正确但双船组合错误 |
| --- | ---: | ---: | ---: | ---: |
| 5 dB | 220 → 221 | 398 → 413 | 53 → 45 | 77 → 70 |
| 0 dB | 210 → 211 | 369 → 375 | 69 → 66 | 90 → 87 |
| −5 dB | 190 → 194 | 317 → 316 | 107 → 103 | 104 → 108 |
| −10 dB | 173 → 172 | 230 → 244 | 181 → 155 | 115 → 119 |

同参数条件下，乘积版的六档 Test 综合 ACC 均高于加法版，六档均值高 0.87 个百分点，五个加噪档均值高 1.00 个百分点。最大差距出现在 5 dB 和 −10 dB，分别高 1.82 和 1.48 个百分点。−10 dB 的 Double 净多判对 14 条，Double 判成 Single 的次数减少 26 次。−5 dB 的 Double 与 −10 dB 的 Single 则由加法版各多判对 1 条。按相同 Val 规则，乘积版的单双均衡分高 0.62 个百分点。

整条交互残差相对 CAT 的五个加噪档平均收益为 1.48 个百分点，CAT 在原始 Test 高 0.80 个百分点。等参数对照进一步支持当前 ShipsEar 划分和种子 13 下保留乘积算子。去分支的对照度量输入缺失及其参与的交互的总效应。 [加法配对统计](../ShipsEar/SE-ABL-ShortLocal-GN-ADD-13/paired_analysis.json) · [CAT 对照](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/ShortLocal-GN直接拼接消融报告.md) · [完整模型分支消融](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/ShortLocal-GN完整模型分支消融报告.md)
