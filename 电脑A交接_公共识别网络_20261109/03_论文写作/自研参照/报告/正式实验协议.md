# 正式实验协议

协议编号 `multitarget-formal-v1`。登记日期为 2026-11-03。本协议覆盖完整模型、固定特征对照、结构消融、外部完整模型及 DeepShip 验证。各组在启动前填写实验登记表，以该表和解析后的运行配置确定实际执行参数。 [统一收尾路线](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/统一收尾路线.md)

## 1. 数据与任务

| 数据版本 | Train／Val／Test | 集合定义 | 原始波形规格 |
| --- | ---: | --- | --- |
| ShipsEar `shipsear_pf_mb_rv_0db` | 2880／716／877 | 背景 E，PF、MB、RV 三种单类集合及三种双类集合，共 7 类 | 16 kHz，5 秒 |
| DeepShip `deepship_multitarget_0db_v1` | 12000／2000／2000 | 背景 E，Cargo、Passengership、Tanker、Tug 四种单类集合及六种双类集合，共 11 类 | 16 kHz，5 秒 |

沿用两套数据各自的现有录音级划分，按数据索引 `array_index` 的顺序对齐 `sample_id`、音频、集合标签和混合条件。数量标签是集合基数 0、1 或 2。DeepShip 的集合输出维数、标签索引、`COUNT_MAP`、分组指标与损失预算使用同一份任务配置。DeepShip 在自身 Train 训练，在自身 Val 选模，在自身 Test 评价。登记源录音归属、混合规则、信道参数、背景来源和场景 SIR，评价中的额外 AWGN 档位另设字段。 [ShipsEar 数据入口（本机出处）](../../../90_本机路径.md#r010) · [DeepShip 数据配置（本机出处）](../../../90_本机路径.md#r011) · [DeepShip 数据汇总（本机出处）](../../../90_本机路径.md#r012)

固定特征组使用各自数据集的全部原始 Train 波形拟合逐维均值和总体标准差。标准差下限为 `1e-6`，保存拟合样本数和实际使用的统计量。训练、Val 与 Test 读取同一份 Train 统计量。 [标准化拟合实现（本机出处）](../../../90_本机路径.md#r013)

## 2. 六档波形与随机流

| 条件顺序 | 原始 | 10 dB | 5 dB | 0 dB | −5 dB | −10 dB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Train 逐样本抽样概率 | 50% | 10% | 10% | 10% | 10% | 10% |
| Val／Test 覆盖 | 全部样本 | 全部样本 | 全部样本 | 全部样本 | 全部样本 | 全部样本 |

首个完整正式训练全程读取正式存储波形，关闭 Single 人工包络。原始档直接读取存储波形，保留生成阶段已有的传播与场景背景。五个含噪档在此波形上叠加 AWGN。全部目标类别与背景采用表中的抽样概率，每轮实际档位数量随抽样波动。

对片段波形 `x` 生成等长高斯向量 `n`，减均值并归一化至单位均方。含目标片段的功率参照 `P_ref = mean(x²)` 使用整段存储混合波形。背景片段的功率参照为 `0.05²`，其 SNR 档位表示相对于该参照功率的附加噪声水平。将噪声乘以 `sqrt(P_ref / 10^(SNR_dB/10))` 后与 `x` 相加，再将整个混合结果的 RMS 归一化到 `0.05`，输出 float32。目标间的 SIR 与额外 AWGN 的 SNR 分别记录。 [AWGN 实现（本机出处）](../../../90_本机路径.md#r014)

| 随机过程 | 已锁定规则 |
| --- | --- |
| 训练初始化 | 完整模型首批训练种子 `13` 和 `42`，遵循模型构造中的初始化约定 |
| 固定特征组每轮样本顺序 | `default_rng([train_seed, 700, epoch]).permutation(N_train)` |
| 训练档位 | `SeedSequence([train_seed, 100, epoch, array_index])` |
| 训练高斯向量 | `SeedSequence([train_seed, 101, epoch, array_index])` |
| 固定特征组批次训练随机流 | `torch.manual_seed(train_seed + epoch * 100000 + step)`，`step` 从 0 开始 |
| Val／Test 主评价 | `SeedSequence([eval_noise_seed, split_code, array_index])`，`eval_noise_seed=13`，Val 的 `split_code=1`，Test 为 `2` |

正式训练轮次从 1 开始编号。同一数据集上的各组共用相同的 Val／Test 样本顺序和评价波形。每个评价样本的五个含噪档使用同一个高斯方向并按档位缩放。主表评价种子统一为 13。独立噪声复测另登记评价种子与参考权重。 [训练和评价随机流实现（本机出处）](../../../90_本机路径.md#r015)

## 3. 完整训练与对照预算

| 项目 | 完整模型及固定特征对照 |
| --- | --- |
| 起点 | 公共识别网络从模型构造所得初值开始。各结构保留其规定的随机或零初始化，固定散射前端无需训练 |
| 首批完整模型训练种子 | 13、42 |
| 优化器与学习率 | AdamW，首个正式方案采用固定 `3e-4`，weight decay `1e-4` |
| 梯度裁剪 | 全局范数 `5` |
| 批量 | 训练与特征提取 `32`，分类评价 `64` |
| 训练与验证预算 | 最少 40 轮，最多 80 轮。每轮遍历完整 Train 并评价六档 Val |
| 早停参数 | patience `10` 轮，主分有效刷新量 `0.2` 个百分点 |

完整模型以最终集合 logits 计算集合交叉熵，另加 `0.1` 倍数量边际监督。每个成员的数量边际概率为其最终集合概率在同一基数下的求和。成员损失取均值后按样本权重聚合。ShipsEar 的背景总预算为 0.1，三个 Single 各 0.1，三个 Double 各 0.2。DeepShip 的背景为 0.1，四个 Single 各 0.075，六个 Double 各 0.1。每个集合的预算按其 Train 样本数均分，沿用训练实现中的样本权重缩放。T0、MLP、Q0、L0 等对照按预先登记的结构和损失定义执行。 [损失实现（本机出处）](../../../90_本机路径.md#r016) · [对照定义](../../../04_历史补充/论文与改造/原始资料/research/shipsear_finalization_20261103/统一收尾路线.md)

固定特征组沿用已有特征计算精度。CUDA 公共识别计算采用 BF16 autocast，随后转 float32 计算各成员 softmax，最后平均成员概率，以最大概率的合法集合为预测。外部模型按各自合理优化配置训练，启动前登记其输入表示、任务适配、初始化、实际批量、学习率日程、最大预算和 Val 调参次数。所有正式组使用共同的数据、加噪、任务和 Val 排序原则。 [模型与评价入口](../../../04_历史补充/论文与改造/原始资料/research/shipsear_final_noise_distribution_20261102/README.md)

## 4. Val 排序、早停与 Test 封存

按下列优先级比较各组自己的实际训练轮次，数值保留计算精度。各项完全相同取较早轮次。

1. `B = mean_六档((Single_ACC + Double_ACC) / 2)`。
2. 六档普通综合 ACC 均值。
3. `min(六档 Single_ACC 均值, 六档 Double_ACC 均值)`。
4. 原始档普通综合 ACC。

每轮用完整排序比较并保存当前最佳权重。早停时钟单独使用主分 `B`。第一次训练后的 Val 分数建立时钟锚点，后续 `B` 相对该锚点累计增加至少 `0.2` 个百分点时更新锚点与最后刷新轮次。较小的主分改善，或主分并列时的次序指标改善，仍可刷新最佳权重。固定特征组达到至少 40 轮后，如距最后一次时钟刷新已有 10 轮，则结束训练。第 80 轮为上限。记录停止原因、最后训练轮次与所选轮次。随机初始化状态作为训练起点登记，最佳权重候选从第 1 轮开始。

正式选模按上列排序执行。相对 V1 的原始、10 dB 和背景保护线属于历史开发采用规则，正式表分别展示各组这些条件的表现与取舍。P50 的开发参考为续训第 20 轮、累计第 71 轮，原试验采用标记为 `chosen_by_Val=None`，Val 平衡增益为 0.901 个百分点。 [P50 封存记录](../../../04_历史补充/论文与改造/原始资料/research/shipsear_final_noise_distribution_20261102/runs/seed13/selection_sealed.json)

训练结束后，写入 Val 封存记录，登记所选权重路径、轮次、排序值及六档 Val 结果。Test 读取封存权重并用同一权重跑完六档。论文主表逐档给出完整集合准确率、Single、Double 和背景准确率，同时给出均值的计算范围。数量准确率、逐集合结果、C0／C1／C2、数量方向误判及固定队列保持率作为补充指标。固定队列记录共同参考权重和原始识别正确的样本 ID。ShipsEar 标记为已参与开发的基准，DeepShip 验证沿冻结方法单独报告。
