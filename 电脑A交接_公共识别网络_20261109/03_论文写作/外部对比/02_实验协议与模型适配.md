# 实验协议与模型适配

## 两套对比的范围

- **ShipsEar 新 MB** 的版本为 shipsear_mb21_33_train_27_50_val_20261104。三船型标签为 PF、MB、RV，加上背景和三种异类双船组合，共七个集合。开发阶段依据已有验证结果调整了 MB 的 Train／Val 录音归属，21、33 号进入 Train，27、50 号进入 Val，随后冻结为四个基线和当前主模型共同使用的划分。原录音隔离，Test 索引和波形沿用调整前的版本。
- **DeepShip PTT** 的版本为 deepship_multitarget_0db_energy80_seen_ship_ptt_v1。在 SeenShip 四船型源数据的原录音划分内，保留 Passengership、Tanker、Tug 及其合法组合和背景，输出七集合。Train、Val、Test 按各自原录音归属筛选。SeenShip 对应已见船舶的新录音评估。

## 共同训练和评价

各方法输入 16 kHz、5 秒单通道的存储波形，从构造初值以种子 13 完整训练。Train 逐样本抽样为原始 50%，10、5、0、−5、−10 dB 各 10%。按方法保留输入前端、优化器、损失和预登记预算。三个直接七集合分类方法均对样本等权计算集合交叉熵，RCMoE 另有专家负载均衡项。TResNet-LA 使用等权的多标签 ASL。采用 BF16 autocast 和梯度范数裁剪 5。

Val 和 Test 每档覆盖各自全集，评测噪声种子为 13。同一数据集内各方法使用相同样本和相同追加噪声视图。同一样本在五个加噪档共享高斯方向，按 SNR 缩放。有船样本的参考功率为存储波形均方，背景样本使用 0.05²，加噪后整体 RMS 归一化到 0.05。原始档读取存储波形。附加 AWGN SNR 和混合时的源间 SIR 分开记录。

Val 首先按六档 Single 与 Double 的等权均值选轮。同分时依次比较六档综合均值、两类六档均值中的较小值和原始档综合 ACC，完全并列取较早轮。封存同一权重后跑六档 Test。TResNet-LA 在无偏置选轮后还有一步 Val 校准。

## 各方法的论文来源和实际适配

- **ShuffleFAC-32** 是 Park 等的轻量船声分类模型。本地使用作者结构及宽度 32，采用 128 频带 HTK 幅度 log-Mel、Hamming 窗 4,096 点和步长 2,048，范围为 0 至 8 kHz，5 秒输入对应 40 帧。分类末层对应七种合法集合。 [作者论文预印本](https://arxiv.org/abs/2601.13679v1) · [作者实现](https://github.com/KNU-LMAP/ShuffleFAC)
- **TResNet-LA** 是 Chen 等针对非目标干扰的水声多目标网络。本地按论文及上游 TResNet 重实现，保留通道注意力和三个存在 logits。使用 128 频带功率 Mel、Hann 512 点、步长 160 点、FFT 1,024，500 帧。输入同谱复制为三通道以匹配 4×4 Space-to-Depth 后的通道数。采用 3×3、步长 1 的 stem 和标准 PyTorch BatchNorm，末端按七个合法集合解码。论文 TIR 与这里的追加 AWGN SNR 分开表述。 [期刊原文](https://doi.org/10.1016/j.eswa.2025.129122) · [上游 TResNet](https://github.com/Alibaba-MIIL/TResNet)
- **Sun–Wang CNN** 取自 Sun 和 Wang 的实值 CNN 多目标路线。本地为 PyTorch 实值 ResNet18 七集合适配。128 频带功率 log-Mel、Hann 480 点、步长 120 点、FFT 1,024，共 663 帧，保留时间维。 [期刊原文](https://doi.org/10.1121/10.0009852) · [作者仓库](https://github.com/QinggangSUN/keras_multiple_target_recognition)
- **RCMoE** 取自 Xie 等的残差卷积混合专家。本地向量化实现四专家 sigmoid top-1 路由、共享残差与 0.01 专家负载均衡。幅度 STFT 采用 Hamming 800 点、步长 400 点、0.97 预加重和片段内标准化，保留 100 Hz 至低于 Nyquist 的频带。运行采用公开残差结构的普通平均池化和七集合头。原论文的注意力池化与本地池化在正文中分别注明。 [期刊原文](https://doi.org/10.1016/j.eswa.2024.123431) · [作者实现](https://github.com/YuanX9/UATR-CMoE)

## TResNet-LA 的统一集合解码

对七个合法集合逐个计算得分「集合内船型 logits 之和 − b × 集合大小」，取最高分。先以 b = 0 选轮，再固定权重，在该数据集六档 Val 上从 0 到 2、步长 0.25 的候选中选一个共享惩罚，同分时取较小值。ShipsEar 的 b = 1.25，DeepShip PTT 的 b = 1.50。正式表使用校准结果，封存 JSON 及 uncalibrated 子目录保留校准前记录。
