## 共同执行规则

1. **公平比较固定任务和评测。** 各组使用本数据集冻结的源录音划分、5 秒／16 kHz 波形、七个合法目标集合和相同的六档评价视图。Train 使用与 Q0 一致的存储波形与 50／10／10／10／10／10 噪声日程。种子 13，从各模型构造初值完整训练。保留各方法适合的前端、损失、优化器和训练轮数。
2. **按 Val 选轮和选配置。** 各组使用冻结协议的六档排序。原始 Val 综合 ACC 约 65–75% 是检查基线是否发挥正常的参考。结合 Single、Double、背景及六档表现判断适配质量。已有的历史 Test 只供解释历史结果，正式配置、阈值和轮次均由预先登记的规则及当前 Val 决定。
3. **限制微调预算。** 首选论文或作者代码的同数据集配置。若 Val 显示未收敛或单项适配明显偏弱，每个方法在每套数据上至多再完整训练一次表中指定的单因素备选。两次都按同一六档排序选用。TResNet-LA 的统一阈值属于封存权重上的 Val 校准，无需加训。所有候选配置、Train／Val 曲线与选择理由留档。
4. **配置封存后评估 Test。** 同一权重跑完六档，报告实际的完整集合综合 ACC、Single／Double／背景和样本数。65–75% 无成绩上限或入表门槛。论文按「同任务适配」标注前端、输出、损失和训练预算的实际差异。

## 首选配置和有限备选

| 编号与模型 | 首选参数 | 单因素备选及适配 |
| --- | --- | --- |
| DS-EXT-SFAC32-PTT-13 · ShuffleFAC-32 | 用作者 DeepShip 配方。128 频带幅度 log-Mel，Hamming 4096 点、步长 2048，0–8 kHz。作者 32 宽结构与池化。Adam `1e-3`、batch 48、普通 CE，最多 200 轮。最少 40 轮，patience 10，早停时钟刷新量 0.2 个百分点 | 5 秒／40 帧和七集合输出为 PTT 适配。Val 数量分组失衡时，备选为同一 CE 加 10／30／60 的背景／Single／Double 组预算。 [论文训练设置](https://arxiv.org/html/2601.13679v1#S3.SS3) · [作者配置](https://github.com/KNU-LMAP/ShuffleFAC/blob/master/default.yaml) |
| DS-EXT-TRLA-PTT-13 · TResNet-LA | 该文参数来源为 ShipsEar。沿用 AdamW `1e-4`、batch 32、80 轮和 ASL 正／负指数 0／6。输入保留 128 频带 Mel，按 16 kHz 采用 512 点 Hann 窗、160 点步长、FFT 1024、0–8 kHz、约 500 帧 | ASL clip 0.05、weight decay `1e-4` 为本地实现值。输出 PTT 的三个存在 logits，按七合法集合解码。统一阈值由 DeepShip Val 独立确定。 [原论文 §5.1 与附录 C](https://doi.org/10.1016/j.eswa.2025.129122) |

TResNet-LA 先以无偏置合法集合读出按六档 Val 选轮。固定权重后，按 `sum(集合内船型 logits) - b × 集合大小` 校准。Val 试 `b = 0, 0.25, …, 2.0`，用六档排序选单一偏置，同分选较小值。封存后跑 Test。首轮适配优先完成校准，保留其无偏置版本供附表核对。
