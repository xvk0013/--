# ShipsEar 机制分析

1. **数量混淆与组合混淆分开统计。** 从同一批封存预测出发，逐档计数 Single→Double、Double→Single、目标→背景、以及数量正确但船型集合错误。真 Double 的错误以全部真 Double 为分母分解，保留分子和样本数。正文聚焦 5／0／−10 dB，附表保留六档。Q0 的 −10 dB 下 528 条 Double 中有 228 条被判为 Single，可作为错误分解的核对点。
2. **同样本配对比较。** 对齐样本 ID、标签、噪声档位后，比较完整 Q0 与双路拼接，并对最强外部方法做相同统计。分别报告纠正数、损坏数、净变化和三种双船型组合命中数。已有逐录音统计可支撑来源分析。
3. **可选补充。** 记录两路特征计算和公共分类的参数量与分段耗时。报告硬件、批量、样本数量、是否包含固定特征计算；缓存后的识别延迟单列。
