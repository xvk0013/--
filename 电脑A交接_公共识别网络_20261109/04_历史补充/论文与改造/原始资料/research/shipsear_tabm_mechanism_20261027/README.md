# 公共TabM成员交互机制对照

## 研究问题与三组模型

本轮检验显式两路交互及成员相关输入适配是否贡献于七种目标集合识别，固定前端结构和末层数量读出，不同时调整损失、数据或其他模块。

| 模型 | 第一层 | 作用 |
|---|---|---|
| P0 | 原TabM线性变换 | 无显式两路交互的基准 |
| P1 | 原变换＋成员共享的乘性交互 | 检验显式跨分支交互 |
| P2 | 原变换＋成员输入适配后的乘性交互 | 检验成员相关交互 |

设两路输入为a（3730维散射统计）、b（320维神经声学表示）；原TabM第k个成员的线性输出为d_k，成员输入／输出缩放为r_k／s_k。

- P0：`h_k = d_k`
- P1：`h_k = d_k + s_k * W[(U a) * (V b)]`
- P2：`h_k = d_k + s_k * W[(U (a*r_k,a)) * (V (b*r_k,b))]`

`*`表示逐元素乘法。U、V和W在成员间共享，交互秩为64。P1的交互内容在输出缩放前共享；它仍保留原TabM成员差异。P1/P2具有相同参数量，仅交互前是否应用成员输入缩放不同。P0参数更少，所以P1>P0不能单独证明交互优于等容量普通非线性映射。

三组后续都是三层TabM、32成员、7类集合输出和末层数量残差读出。每个成员先softmax，再平均概率。没有真实数量、类别或SNR作为推理输入。

## 初始化与训练

只从`shipsear_tabm_internal_audit_20261027/runs/seed13/C1_late_count_readout_best.pt`继承神经编码器和Train拟合的标准化参数，不继承公共TabM或优化器。该源模型的训练谱系是：随机初始化的神经—散射G2源实验所选第22轮 → 公共读出对照续训第8轮。

公共TabM共有部分随机初始化后复制到三组；P1/P2新增投影初值完全相同，交互输出W零初始化；三组数量残差读出均零初始化。因此三组初始输出一致。源编码器先前已与G2共同训练，本轮回答的是在这一共同任务起点上不同公共结构的差异，不等于独立从零建模的最终消融。

固定数据排列、种子13、噪声视图、样本权重和损失。TabM学习率0.001，编码器0.0001，全网络共同适配。最少20轮，最多40轮；三组均连续10轮Val选模分数未提升时共同停止。每组选择一个检查点，原始及五档噪声使用同一权重。

Val分数：0.5×原始条件Single/Double/背景宏平均＋0.5×五档噪声宏平均的均值；平分比较原始综合ACC。封存选模后评价Test。第0轮也可选，但不另设针对Test的阈值。

## 预先确定的判断方式

1. P1/P2比P0：显式交互是否改善集合识别，以及是否只是移动数量偏向。
2. P2比等参数P1：成员输入适配是否有独立价值，主要观察六档结果、数量错误与条件类型ACC。
3. 成员共同犯错是否减少；分歧增大本身不算收益。
4. 检查同轮Val差异，避免把一次选模波动当作机制证明。
5. 当前C1历史性能仅作工作基线，不与本轮公共分类器重训混称同一起点比较。

若成员相关交互贡献清楚，转向双分支补强；若只共享交互有效，下一步再针对成员算子做限定改造；若简单结构同样有效，停止堆叠公共模块，优先诊断分支证据。单种子结果是机制候选筛选，不能据此宣布学术新颖性或统计稳定性。

## 文件

- `model.py`：三组结构及仅编码器继承逻辑。
- `run.py`、`config.json`：统一训练、封存选模、六档测试。
- `smoke.py`、`validation.json`：真实波形初始一致性与两步梯度验证。
- `analyze.py`：推理回放、交互敏感性及报告。
- `runs/seed13/`：权重、逐样本／逐录音输出、历史与结果。
