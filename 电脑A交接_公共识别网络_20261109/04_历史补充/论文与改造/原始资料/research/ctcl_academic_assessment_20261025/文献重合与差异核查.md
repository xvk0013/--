# CTCL 文献重合与差异核查

核查日期：2026-10-25。对象：桌面《低信噪比水声多目标识别_创新点可行性评估.md》中的 A / A+。以下区分论文已报告的方法、本项目既有证据，以及尚待实验的推论。未训练模型或修改数据。

**判断：基础“完整混合—移除成分—对应类别分数下降”已经有音频方法近邻，而且本项目已经实施过。较值得研究的剩余假设是：在共享背景和传播条件下，匹配干扰能否帮助学习新增目标对类别与数量的选择性响应。它目前是可证伪的机制假设，不能据检索结果认定首创或预期收益。**

## 2. 本项目内部已经做过什么

已核对[《数量路由与源干预证据实验报告》（本机出处）](../../../../../90_本机路径.md#r376)：A/B/C 均看到相同主样本及真实移源视图；B 增加逐类存在监督；C 再约束移除类别后的对应证据和双目标数量优势下降。C 的 Test 综合 **86.66%** 与普通监督 A 相同，Val **77.65%** 低于统一路由基线 **79.89%**。Train 中移除类证据下降 **2.243**，保留类也下降 **2.093**。因此基础 CTCL 不只是文献上常见，还是本项目已经检验过、未显示独立收益的方案。

真正的新问题是如何消除这种共同下降并使选择性证据改善最终数量路由。旧实验中各派生波形独立归一至同 RMS；新研究若要识别贡献差异，应重新明确干预前的公共幅度基准，避免归一化同时改变保留目标和背景。

## 3. 干预对象必须准确命名

按给定生成事实，设原录音成分为 `r_k = v_k + b_k`（船声加该录音的环境声），传播后成分 `s_k = H_k(r_k)`，合成输入 `x = n + Σ s_k`。删除已知 `s_k` 可精确实现**合成器中录音成分的干预**，但同时删除 `H_k(b_k)`。它不等于只让真实船舶 `v_k` 消失、保持环境声不变。

建议论文使用“已知传播录音成分的受控增删”或“成分级反事实监督”。若声称“真实船源因果贡献”，还需要船声与录音背景的可分辨证据；同一份 ShipsEar 混合标签不足以提供该识别。此结论来自生成模型的直接推导，不是某篇论文已经替本项目证明的事实。

## 4. A+ 何时具有实质差异

可用共享背景、传播与幅度的三个**视图**：`x0 = A + n`、`xB = A + B + n`、`xP = A + u + n`。`u` 必须确认不含 PF/MB/RV 目标；“三视图”不增加三目标任务。此处数量始终是当前标签的目标船型数，不是所有物理发声体数。

令 `e_j` 是硬数量路由之前的类别证据，`d_j^B = e_j(xB)-e_j(x0)`，`d_j^P = e_j(xP)-e_j(x0)`。若所谓新损失只有 `d_B^B > d_B^P + m`，公共基准会抵消，**代数上就是 `e_B(xB) > e_B(xP)+m` 的普通配对排序**。命名为“双差”或“因果对比”不改变这一点。

较可辩护的候选应明确同时检验：新增 B 的类别响应具有选择性；保留 A 的证据不发生无区分共同漂移；真实新增 B 支持 `1→2` 的目标数量变化，而有效非目标 `u` 对应 `1→1`。在低可辨性、强掩蔽情况下，不应假定所有样本都能满足同一个严格正间隔。上述是待验证设计方向，不是文献空白或收益保证。

根据当前结构，融合七集合概率在数量修正 MLP 之前。只在七集合存在边缘上施加损失，不会直接更新下游数量头/MLP；若主张解决 Single/Double 路由瓶颈，需要可训练的数量响应监督及对应消融。**旧 C 已有数量优势成对约束，仅增加数量 margin 仍不是新的增量。**类别诊断应在硬路由之前计算，否则数量裁剪本身即可制造类别分差。

## 5. 等能量、等频谱安慰剂的关键风险

1. **等新增成分功率不等于等混合总功率。** 对上下文 `a`，`||a+B||²-||a+u||² = 2⟨a,B-u⟩` 在 `||B||²=||u||²` 时仍可非零。共享上下文、足够多独立安慰剂实例并记录实测总功率和频带分布，比重新逐视图 RMS 归一更便于解释；后者会一并改变 A、n 的有效幅度。
2. **等频谱不保证负标签有效。** 对 B 相位随机化保留 `|FFT(B)|`，也可能保留船型相关谱线/谱包络。对于依赖这些统计的散射分支，“它听起来像噪声”不足以证明“它不含 B 证据”。相位替代物宜先作为诊断或软控制，不能直接硬标为 B 不存在。
3. **等频谱仍可改变掩蔽、包络与调制。** [Clonan 等](https://pmc.ncbi.nlm.nih.gov/articles/PMC12330335/)显示这种差异可在固定 SNR 下改变目标识别。把所有响应差都解释成语义特异性，会混入可辨性变化。应分别报告目标边缘增量、保留类漂移和数量增量。
4. **控制越严格，越可能保留任务证据；控制越粗，越容易学到生成痕迹。** 至少区分真实非目标录音匹配、仅功率匹配、较粗频带匹配、相位替代诊断；比较跨控制族表现。保持 Train 内源录音来源约束，不从 Val/Test 取得匹配模板或样本。

最小有意义的证据链是：相同起点/预算/视图下的普通监督 → 标准类别及数量排序 → 新选择性约束；另用安慰剂类型消融排除功率捷径和生成痕迹。主要验收不仅是分差变大，还包括固定协议下低 SNR 的 Single/Double、背景误报、数量混淆及最终七集合识别。已有 Test 被历史开发使用的事实应保留说明，recording-disjoint 本身不会重置这一使用历史。

**可保留的投稿主张边界：在已知传播录音成分可控的多目标识别中，研究匹配干扰能否让类别与数量的干预响应更有选择性，并带来超越同数据增强和普通排序的跨录音收益。当前证据支持开展这一验证，不支持把基础 CTCL 或“等能量非目标噪声”直接宣布为核心学术创新。**
