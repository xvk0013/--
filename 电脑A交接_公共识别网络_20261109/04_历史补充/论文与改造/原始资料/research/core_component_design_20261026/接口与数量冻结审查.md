# 可解释成分推断：接口与数量冻结审查

日期：2026-10-26。本文为只读方案审查，不实现、不训练。采用原H1完整版本作为共同起点，研究类别分组成分推断能否提供超出原32成员选择器的类别证据。

## 1. 必须先明确的结构事实

原H1的数量修正输入为基础数量概率3维、TabM成员平均7维、成员选择器融合7维。后7维一旦换成新类别评分，最终数量概率也会变化，即使数量头和17维MLP的参数完全不动。因此“参数冻结”不等于“数量判断冻结”。

原H1推理得到的q_anchor可以在机制试验中隔离这种变化，但其计算仍依赖旧选择器。只要新录音的推理还要调用它，就不能说最终结构已删除旧选择器。阶段1应明确标为局部方法试验，阶段2才完成数量上下文适配与结构删除。

## 2. 阶段1：只检验新类别证据

### 共同冻结条件

所有组沿用同一H1声学/DEMON编码、散射、TabM、抗噪前端、数据划分和追加噪声规则。除原H1对照外，类别基底均为TabM32成员固定等权。新方法读取冻结编码器的局部时频图和同一混合波形的非负线性谱，不只读取320维均值向量。

每个实际输入视图都由原H1得到q_anchor。Train在线噪声更换时，需对该实际视图计算或缓存对应q_anchor；不能把无额外噪声的数量缓存用于另一份含噪波形。Val/Test对应保存或重算相同波形的anchor。q_anchor不依赖真实数量、船型标签或源成分。

所有组使用完全相同的q_anchor选择0/1/2词表，组间数量错误逐样本相同。此阶段的新类别模型不会修复数量本身，评价目标是给定同一路由时的新船型证据是否有效。

### 四组安排

|组别|类别路径|数量路径|训练职责|
|---|---|---|---|
|R0 原完整模型|原32成员选择器|原H1 q_anchor|固定性能参照|
|R1 删除选择器|32成员等权概率|相同q_anchor|无需新类别训练，量化删除代价|
|R2 普通成分估计|等权基底＋普通非负激活估计器的直接集合修正|相同q_anchor|与R3同输入、同字典、同源监督、同读出；估计器用普通前馈网络|
|R3 分组展开推断|等权基底＋分组展开的直接集合修正|相同q_anchor|研究展开推断结构本身的价值|

R2不是再训练一个只读旧全局特征的普通七类MLP。它应从与R3相同的局部神经特征/线性谱估计同一形状的非负字典激活，接受同一重建、源激活与集合监督，并使用相同最终读出。这样才能排除额外信息、源监督和更大头部解释全部收益。

原R0/R1是固定结构参照，不冒充与R2/R3同预算训练的算法对照；R2/R3才承担最核心的同预算方法比较。

### 新核心的直接输出接口

设成员等权七集合概率为p_eq，新成分推断得到激活H，公共读出给出七集合修正r(H)：

```text
new_logits = log(p_eq) + r(H)
p_new = softmax(new_logits)
prediction = route(q_anchor, p_new)
```

这使新类别证据直接改变最终词表内排序，不再受原“每种数量内32成员共同非负加权”的表达边界限制。r(H)及字典激活可受源监督，但不能只训练一个辅助成分头、最终仍只用旧概率。

是否采用残差基底必须事先固定。若保留等权基底，应记录新修正的实际救回与误伤；被关闭后预测完全不变，就不能把该核心当作有效贡献。不能在最后再由一个自由分类旁路绕过H输出全部r。

为防止末端自由七类MLP重新承担全部识别，可在R2/R3共同固定“类组激活汇聚 → 三类存在概率rho → 七集合成员关系评分”的读出，例如r(S)=sum_c[1(c∈S)log(rho_c)+1(c∉S)log(1−rho_c)]。这是普通集合读出，不作为新创新；新方法的价值必须来自H的推断。若采用其他读出，也应保持R2/R3完全一致，并禁止神经上下文直接绕过H预测七集合修正。

## 3. 成分推断的最小任务定义

可将字典按PF、MB、RV及非目标分组，输入是非负线性谱V，输出所有组的非负激活H_g。普通估计器和展开候选使用相同字典初始化、激活尺寸与集合读出。展开层通过已有优化问题的有限步推断估计激活，局部神经时频信息可调制阈值或收缩规则；不能直接从该上下文另开无约束七类旁路，使展开支路成为装饰。

所有类别字典在推理时都开放。真实集合、真实数量和Train源成分只能监督训练，不能在推理时关闭缺席类字典或指定活动组数。

Train源监督可由索引中的传播后成分按同一视图实际增益恢复，再形成各组谱目标或字典激活参考。追加噪声应纳入非目标参考。源成分需共用该混合视图的归一化增益；不能各自独立归一化后仍称为原混合贡献比例。

必须明确近似边界：波形线性相加不意味着单次幅度谱、功率谱、散射或深层特征严格相加。正字典的谱重建应是表示学习的近似约束，不能把有限片段的相位干涉残差强行标成“新目标”或声称得到精确物理源分解。原船声成分也保留自然环境，不是纯净船体声。

## 4. 阶段1的进入/停止条件

方法价值需要同时对照R0、R1和R2：

- 超过R1只说明能恢复或补充删除后的类别能力；若仍明显不如R0，不能据此说整体新结构优越。
- 超过R2才支持展开/分组机制具有普通成分估计以外的独立价值；只超过R1不足以证明核心方法。
- 比较实际路由固定下的Single类型、Double组合错误，以及真实数量条件下的诊断类型能力；后者不是可保证达到的最终ACC。
- 观察被误判样本的源激活/类别证据是否按预定语义改善。仅重建更好或辅助源预测更准，不自动通过。
- 所有组路由错误相同，因此本阶段无需用数量ACC涨点作为机制证明，也不能因为综合提升受固定数量上限限制而随意改动数量头。

整体可接受损失、目标问题改善幅度和Val选模在启动前确定。阶段1未通过时，停止候选，不靠数量接口调参把类别机制包装成成功。

## 5. 阶段2：数量上下文适配后真正删除旧选择器

阶段1通过后，R1/R2/R3的17维读出统一改成：

```text
[base_count_prob(3), mean_TabM_prob(7), p_new(7)]
```

R1的p_new即p_eq，R2/R3为各自修正后的未路由七集合概率。不要先用q_anchor硬裁剪p_new再送回数量读出，否则产生数量自反馈并隐藏真实信息变化。

各组从相同H1基础数量头/17维MLP状态开始，按相同数据、噪声视图、优化步数与选模规则训练受影响的数量接口及新类别接口；声学编码和散射/TabM先维持固定。R0可保留原H1作为性能参照；正式比较若要排除单纯数量续训的收益，应加同预算R0继续训练。阶段2不再以缓存q_anchor作为最终预测数量。

最小实际运行可以先适配R2/R3及R1，原R0作固定参照；无需把失败阶段1全部重复训练。若完整论文主张新框架比同预算原模型更优，则正式阶段补R0同预算数量续训，而不是把固定R0当成严格训练对照。

q_anchor可作共同训练期教师，但如采用蒸馏，R1/R2/R3都应得到相同监督，不能只给候选提供旧强模型知识。推理必须由当前基础数量头和当前数量MLP生成q_new，不调用旧选择器、不读取旧逐样本缓存、不读取噪声或数量真值。只有此时旧选择器才真正退出完整模型。

此阶段重点检查原始误伤、低SNR Single救回、Double损失和背景，同时确认阶段1的类别机制收益仍保留。若仅数量适配产生改善，收益归因于接口适配；不能全部计入成分推断创新。

## 6. 最必要对照的作用

|对照|排除的替代解释|
|---|---|
|原H1 R0|新方法是否只恢复人为删掉的既有能力|
|等权R1|旧成员选择器实际贡献与删除代价|
|同输入同监督普通成分估计R2|额外局部谱、源监督、读出容量已足够带来收益|
|完整展开R3|受结构约束的推断本身是否有独立价值|
|最终必要组件消融|若R3有效，再区分分组、上下文收缩、源监督各自作用|

完整组件消融留到核心成立之后。整个安排研究的是能进入最终类别判断的成分推断，而非为了给新模块留位置人为降低基线要求。
