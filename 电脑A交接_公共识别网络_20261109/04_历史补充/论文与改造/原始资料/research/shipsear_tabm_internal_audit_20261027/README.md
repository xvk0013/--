# 公共TabM内部诊断与读出位置对照

## 本轮问题

在同一套数据和神经—散射输入上，G2提高低信噪比Double准确率，却加重Single→Double误判。本轮先检查问题位置，再尝试局部改造，不改前端结构和数据排列。

诊断使用此前选中的G2权重，仅使用Train和Val。已有Test结果不参与本轮诊断参数选择。`audit.py`包含三个检验：交互项强度敏感性、成员概率汇总替代、同容量线性数量探针对不同隐藏层的比较。线性探针在Train原始视图和独立−10 dB视图拟合，在Val评价；它不是完整模型，也不代表可实现性能上限。

## 诊断发现与改造理由

- 关闭交互后，Val −10 dB的Single→Double误判由92增至138。交互项不是可以直接移除的冗余部分。
- Single交互项／直通项的RMS比中位数从原始条件0.556降至−10 dB的0.311，没有发现交互幅度随噪声失控放大的现象。这不能排除交互方向或训练共适应问题。
- 平均logit、概率中位数没有呈现一致的改进。给全部Double统一减分也主要移动Single与Double的取舍：Val综合选模分数仅增加约0.09个百分点。
- 同容量线性探针：第一层／末层的原始Val数量ACC为82.68%／77.79%，−10 dB为75.56%／74.72%。浅层信息值得尝试，但低信噪比优势很小；这些数值也不说明探针强于现有完整读出。

## 三组对照

| 组别 | 改动 | 检验目的 |
|---|---|---|
| C0 | 原G2继续训练 | 排除额外训练带来的收益 |
| C1 | 从TabM末层补充数量残差 | 控制参数增加与输出重参数化 |
| C2 | 从TabM第一层补充数量残差 | 检验早期数量证据绕过后续隐藏层是否有用 |

对第k个成员、第s种集合，新的logit为：

`z_new[k,s] = z_old[k,s] + c[k, count(s)]`

`c`为可学习的三输出线性读出；C1读取末层、C2读取第一层，均为32个成员各自的读出。新权重和偏置全部零初始化。最终仍计算每个成员的七类softmax，平均成员概率，选择最终集合；不输入真实数量，不做数量硬路由。

在隐藏特征固定时，这一操作不改变**同一个成员内部**三个Single船型之间、三个Double组合之间的相对logit。不同成员的数量概率会改变它们在集合汇总中的相对贡献，因此最终平均概率的条件船型排序仍可能变化；联合训练还会改变隐藏特征。需要同时观察条件船型／组合ACC，不能假定它们保持不变。

C1的线性组残差可以吸收到原末层线性分类头中，因此主要控制优化参数化。C2增加从第一层到集合评分的跨层路径，才真正检验读出位置。此轮不将残差读出或跨层连接直接认定为学术创新。

## 训练与判断

- 三组继承同一个`shipsear_tabm_neural_scratch_20261027`中N2第22轮任务权重；不是三次独立从零训练，也没有加载BEATs预训练权重。
- 原始源实验从随机初始化训练。本轮保留其Train拟合的标准化参数，三组重置AdamW优化器，公共TabM学习率0.0003、编码器0.0001。
- 数据排列、种子13、在线加噪分布、样本损失权重、损失定义、评价噪声保持一致。公共TabM、M2及DEMON一起训练，避免只接新头却不适配上下文。
- 共同训练20轮，每组按同一Val分数选择一个检查点；初始第0轮也可被选中。选模完成后才评价六档Test。
- 主要检验：相对同预算C0，是否减少Single→Double并改善Single，是否只是把错误转移成Double→Single；同时报告整体ACC、Double、背景与条件识别。评价结果允许否定方案，不靠挑一个信噪比宣布成功。
- 若要进一步保留为正式结构，应同时看Val选择证据和完整Test曲线；本轮单种子局部适配不等于最终论文消融。
