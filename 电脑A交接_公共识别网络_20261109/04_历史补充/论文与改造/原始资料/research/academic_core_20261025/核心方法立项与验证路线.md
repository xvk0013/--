# 核心方法立项与验证路线

日期：2026-10-25。根据用户最新要求，本阶段先确立方法贡献，再围绕该方法优化模型。本文不启动训练、不修改模型或数据。

## 1. 当前决定

现有H-transfer完整模型作为冻结的性能参照和方法测试载体保留。匹配负对照贡献学习阶段2未通过，停止将该版机制作为核心贡献推进。此前数量修正MLP、数量读出和公共集成接口的工程优化安排暂停，不因某项容易涨点便自动启动。

当前顺序固定为：研究问题与方法立项 → 最小机制验证 → 接入完整模型 → 围绕已成立机制优化 → 正式消融与对比。

核心方法可以来自其他领域的成熟结构。需要明确原方法、任务差异、实质改造及对应证据；不要求从零发明整个网络，也不以模块较新、名称特别或换入后偶然涨点作为充分依据。

## 2. 候选立项必须回答的五个问题

1. **问题是什么？** 指定一种可观察错误或缺失能力，提出可证伪的成因假设。跨录音表征纠缠、目标共现信息不足和数量路由偏移是不同问题，不在同一候选中全部承诺解决。
2. **原方法是什么？** 给出一手来源、原始机制及适用假设。保持对原作者的归属说明。
3. **我们改了什么？** 写出具体计算、信息流或监督的改造，解释水声多目标任务为何需要这种改造。只换应用名称或调整维度不作为方法贡献。
4. **替换哪里？** 在现有模型图中标出旧模块、新模块、输入输出和训练范围。优先替换一个明确接口，不持续叠加平行分支。
5. **怎样判定成立？** 先写对应机制指标及识别指标、比较组和采用条件，再训练。只改善训练约束或某一置信度分差，不等于解决目标问题。

立项说明完整后才进入实现。不能先把全部结构拼好，再根据最高成绩倒推核心创新。

## 3. 最小验证与切换条件

|步骤|本步工作|进入下一步的条件|
|---|---|---|
|方法筛选|核对一手论文、历史实验重合、现有接口及监督可用性|选定一个机制，能解释问题、实质改造和失败条件|
|最小验证|在固定数据和共同起点上比较基础接口与新方法；方法适配贡献需安排原方法对照|所声称问题在Val及机制诊断上获得一致改善，整体损失在预先约定范围内|
|接入整模|适配新模块相邻接口，训练受影响部分，其他条件配对|机制收益在完整推理链中保留；不能依靠真实数量或源音频参与推理|
|性能优化|只围绕已成立方法调整必要结构和训练|同一完整版本达到约定性能，或明确剩余差距并讨论范围|
|正式论证|核心组件消融、强基础方法及必要外部模型对比|主张、方法和证据对应，进入报告与论文整理|

基础对照按接口选择同输入、同预算的MLP、平均/注意力汇聚或普通二阶统计。研究方法的任务适配时，原方法与适配方法的差异也需验证。组件消融在候选形成识别收益后补齐，避免对尚未成立的候选一次性训练全套实验。

不要求核心方法在所有条件、所有指标上全面领先；要求它在所声称解决的问题上有独立、可重复的价值，并满足事先约定的整体性能范围。若效果相近，只能保留为候选，不能宣布创新成立。关键重复仍只考虑13/42/2026，不展开种子搜索。

## 4. 本轮文献筛选的两个候选方向

以下是方法来源及研究启发，尚未立项，不代表已决定替换模块。

### A. 类别语义与环境因素的表征解耦

Nam等的[Interspeech 2024论文](https://www.isca-archive.org/interspeech_2024/nam24b_interspeech.pdf)通过可接在既有嵌入提取器后的自编码器，分离说话人信息与环境信息，并结合重建、环境约束及嵌入交换。原研究对象是说话人识别，不直接证明水声多目标有效。

可考察的替换位置是编码后、数量与船型读出前的特征投影。水声任务的适配问题是：保留弱第二目标与组合信息，同时削弱传播、噪声等环境因素。不能把全部录音身份差异当作干扰删除，因为当前录音与船型相关，也不能要求所有能量差异都不影响目标数量。需要先定义哪些因素可以受控变化、哪些证据必须保留。

### B. 保留目标共现关系的二阶时间汇聚

当前实现对神经时频特征图进行全局均值汇聚。可研究用关系统计替换这一接口，检验不同特征共同变化的信息能否支持混合目标判断。[矩阵函数与协方差汇聚研究](https://arxiv.org/abs/2407.10484)和[RHOP，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/7d2b770c3ccd35b41c9453ef6f8765a3-Abstract-Conference.html)提供可核对的方法背景。

协方差汇聚本身已有长期研究，不能直接改名当作本项目原创。立项必须提出针对混合目标与噪声的具体改造，并比较普通均值、注意力及普通协方差。神经通道协方差的秩也不能直接解释为目标数量。

A/B只保留为待审候选，先比较方法与任务的适配程度，不并行启动两条训练线，不将任何一种提前写为已成立创新。

## 5. 论文贡献的组织原则

用一个明确研究问题、一套承载框架和一个经过证明的核心方法组织论文。异构框架可继续保留为体系结构；核心贡献可以位于其中一个分支或中间汇聚模块，不强制落在最终数量决策，也不硬凑三个互相独立的原创网络。

当前最重要的交付是一个能够落到计算、替换位置和证据的核心方法方案，而不是继续提高旧模型分数。
