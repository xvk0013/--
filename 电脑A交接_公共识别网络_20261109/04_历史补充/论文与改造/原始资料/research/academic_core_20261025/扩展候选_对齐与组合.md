# 扩展候选：部分输运与跨录音多原型

日期：2026-10-25。本文仅研究，不训练、不改当前模型。以下任务设计与排序均为基于现有信息的研究判断，原论文的成功不能直接推断水声任务收益。

## 1. 较值得保留：类别相关局部特征的部分输运汇聚

### 原始依据

- Fang、Chen、Xue，**On inferring prototypes for multi-label few-shot learning via partial aggregation**，Pattern Recognition 164 (2025) 111482，DOI：[10.1016/j.patcog.2025.111482](https://doi.org/10.1016/j.patcog.2025.111482)。已读取[作者机构全文](https://palm.seu.edu.cn/hxue/publications/On%20Inferring%20Prototypes%20for%20Multi-Label%20Few-Shot%20Learning%20via%20Partial%20Aggregation.pdf)第3–5页方法部分，未找到作者代码地址。
- ProPOT针对多标签少样本图像的类别原型被其他对象和背景污染，利用部分最优传输选择类别相关局部区域，形成support类别原型，query通过全局特征与原型距离分类。原法有CLIP文本/视觉对齐及有标签support；部分质量与support标签数相关。不能把它描述成已经解决无标签query数量问题的即插即用模块。
- PLOT（ICLR 2023）是局部特征与多个类别描述之间的OT匹配近邻，针对单个全局匹配使多个描述趋同的问题。[原文](https://arxiv.org/html/2210.01253)，[作者代码](https://github.com/CHENGY12/PLOT)。本轮核实其方法与代码入口，未进行完整复现。

### 为什么与我们的任务有关

当前神经分支最后采用时频特征全局平均，三类混合目标的局部证据可能与背景共同汇总。部分输运提供的研究抓手是：允许无关局部质量不被分配给任何目标，从局部特征中产生类别相关表示。它比对两路全局向量强行做分布对齐更贴近混合目标与噪声问题。

### 拟替换位置与实质改造

替换神经时频图到类别读出的汇聚/类别查询接口：局部token → 低维投影 → 类别相关部分分配 → 类别表示。散射与TabM先保留，后续分类/数量接口只做必要适配。

这不是直接照搬ProPOT。需要以Train数据学习的类别字典代替CLIP文字语义；在固定三类0/1/2任务中处理缺席类与背景；允许两个类同时得到支持，而非把时频位置硬排他地分给唯一类别。不能把图像局部互斥假设直接当作声音叠加的物理规律。

最关键的新设计是未知数量下的输运质量：ProPOT原文使用有标签support的类别数设置部分质量，我们推理时不能提供真实数量来设质量或屏蔽类别。可以研究有背景保留项、类别支持稀疏度或非平衡质量的分配，但在其定义与监督没有明确前，不能启动整轮训练。

保守替代是只用Train带标签样本通过POT生成固定类别原型，再对待测样本预测；它不依赖Test支持标签，但较接近旧原型接口，学术区分与新增价值需更仔细检查。

### 与旧尝试的区别及最低对照

旧原型差分在冻结全局表示上加最后组合分数；本候选需要在汇聚前学习类别相关局部成分。旧类别query是普通注意力；这里的关键应是允许丢弃无关质量的分配约束。若两者表现相同，不能仅凭Sinkhorn名字宣称机制贡献。

最低对照应包括：相同token与输出维度的普通注意力、平衡OT、拟议部分/非平衡分配；比较类别/组合错误、Single↔Double路由误判与整体识别。必须检查“背景质量”是否真的对应非目标干扰，而不是吸走弱第二目标。所有原型/分配参数只从Train学习，推理不增加Test域适配、不读取源成分或真实数量。

### 可行性与风险判断

方法依据较直接，模块位置明确，三类使求解规模可控制。但标签只监督整段类别，局部分配未必可辨识；弱目标易被当作未分配背景；自然声重叠未必具有图像式局部纯净区域；估计质量可能重新变成隐式数量阈值。当前不应排在低改动的二阶汇聚或监督定义更清晰的解耦之前，可列为中后优先的研究候选。

## 2. 保留为后备：跨条件多原型的类别成分表示

### 原始依据

Qu等，**Learning Clustering-based Prototypes for Compositional Zero-Shot Learning**，ICLR 2025。[正式会议页](https://proceedings.iclr.cc/paper_files/paper/2025/hash/10b99813d5992673da90a499b6bcd5f0-Abstract-Conference.html)，[作者仓库](https://github.com/quhongyu/ClusPro)。ClusPro用同一原始概念的多种原型表示类内变化，而非一个中心，并通过原型学习及概念间解耦塑造表示空间。原任务是属性—对象的组合零样本识别。

本轮查看了作者`cluspro.py`：代码包含CLIP、概念适配器、原型队列、聚类与对比相关组件，不是可以原样放进水声模型的小型分类头；仓库依赖和完整复现尚未核查。[作者源代码](https://raw.githubusercontent.com/quhongyu/ClusPro/main/cluspro.py)。

### 本任务可研究什么

PF、MB、RV各自跨录音和条件差异大，单一中心可能把类别内部变化当作类间差异。可在读出前学习每类少量跨条件原型，并由这些原型产生类别成分表示。与旧固定原型修正的实质区别必须是原型同时参与表征学习，并验证不同原型是否覆盖类别条件变化，而非只是记忆某一录音。

原型库只能从Train构造，按来源录音组织训练时的正负关系，避免同源片段支配。不能根据Test困难录音更新库。也不应直接把两个单类原型相加当作混合表示：波形线性叠加不意味着散射、幅度谱或神经特征线性相加。

### 最低对照与排序

对比单中心原型、相同数量的无约束多中心、带任务适配的多原型表示；使用相同底座/训练预算。除整体识别，还需检查留出录音是否受益、原型是否退化为录音ID聚类、Double组合是否真正由类别成分支持。

优先级较低：已有原型差分与KAN未带来收益；现任务三种Double组合都在Train出现，不能照搬“未见组合零样本泛化”的论文叙事；源录音数有限，增加原型可能只增加记忆。它是新的表征研究候选，而不是把旧原型结果改名再做。

## 3. 暂不推荐普通跨分支全局OT

AAAI 2025的[An Optimal Transport-based Latent Mixer for Robust Multi-modal Learning](https://ojs.aaai.org/index.php/AAAI/article/view/33849)研究未对齐、分布式多模态数据，以局部Wasserstein自编码器和融合Gromov–Wasserstein重心做潜变量混合。当前神经/散射两路来自同一段音频，样本配对关系已知，原问题与该论文不同。

直接把320维神经向量与3730维散射统计投影后做全局OT，可能只是重复已有共同/私有表征路线，并损坏有用的分支差异。除非先定义缺少的局部语义对应及不可对齐质量，否则不因OT较新或数学复杂而列为优先创新。

## 4. 给主线排序的建议

优先级由问题针对性、可定义的任务改造、现有证据和最低验证成本共同决定。建议上述两类放在已有解耦/二阶候选之后，其中“部分输运的局部类别表示”高于“多原型重建整套表示”。若分配语义无法定义，或必须借助推理真实数量，则停止该候选，而不是把它重新包装为一个末端数量修正器。
