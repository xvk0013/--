# 类别归属与训练分工的小闭环实验

2026-10-26。固定原录音排列、正式波形、0/1/2目标任务与种子13。原H1完整模型保留；本轮只训练新成分核心及其读出，不改神经主干、散射/TabM、波形前端或数量路径。

## 两个因素、一个普通对照

|组别|成分估计|字典|分类梯度进入成分核心|
|---|---|---|---|
|P0|四步展开|固定|共同预热后进入|
|P1|四步展开|源类别归属训练|共同预热后进入|
|P2|四步展开|固定|停止|
|P3（预设候选）|四步展开|源类别归属训练|停止|
|P4|普通非负预测器|源类别归属训练|停止|

P1−P0、P3−P2检验字典归属学习；P2−P0、P3−P1检验分类/成分梯度分工；P3−P4检验展开的独立价值。分别判断各因素，不把预设P3全部成功当作其它因素有无价值的唯一结论。

P0是按共同协议实际重训的控制，不是直接引用上一轮R3成绩。五组新模块同种子重置；仅继承相同任务训练的冻结声学底座和H1数量能力。

## 字典怎样接受类别归属监督

沿用Train已生成的源组件功率缓存和初始字典，不新增WAV、不重排数据、不复制约1.9GB缓存。源谱依旧是正式输入责任分配近似，不解释为纯船舶声物理分离。

对每个已知Train类别成分的平均频谱，分别用PF/MB/RV/残余四组字典作相同八步非负KL系数推断。对比哪个组更适合解释该来源，监督真实组获得更低解释代价。只使用实际存在船型及背景样本的残余组，逐父样本平均，不让双目标额外扩大监督预算。

P1/P3/P4字典接受该对比与原成分目标训练，并由初始模板锚定；每次更新投影到非负、列归一字典。对比温度0.2、对比权重0.1、锚定权重0.05均预先固定，无搜索。固定字典组同样记录归属诊断，但不据其常量损失更新参数。

## 分类与成分怎样分工

所有组共用前三轮成分核心预热：分类读出接受停止梯度的成分激活，核心由来源目标训练。第4轮开始，P0/P1允许分类误差回传核心；P2/P3/P4继续停止这条梯度。停止梯度保持同一个前向计算，不增加推理分支、不输入真实标签。

每组总计30轮，预热包含在30轮内。每个父样本每轮一份相同在线AWGN视图，五组共享每批冻结特征。原始/10/5/0/−5/−10 dB概率保持30/10/10/10/20/20%，不追加条件相关Single包络。

核心/字典与分类读出分别做同阈值梯度裁剪，避免停止梯度后，分类梯度仍通过共享裁剪系数间接影响核心更新。

## 评价与停止规则

统一以0.5原始Val综合ACC＋0.5五档含噪Val综合均值，选一个实际训练轮次；epoch0另列。模型封存后再读取相同54个留出Val样本来源作成分与归属诊断，源不用于训练或选模。

成分恢复必须在含船样本上优于零成分参照（相对L1<1），并优于同协议普通P4；缺席类别激活受控，类别字典在未知录音的对应组应有解释优势。识别同时比较统一Val、低三档、逐组合、救回与误伤。候选相对P4的统一Val需更高，低三档至少+1个百分点或−10 dB至少+2个百分点，才通过本轮识别筛选。来源与识别两项分别报告。

所有版本仍共用原H1对当前实际波形的预测数量。本轮不能解决冻结的数量误判，也不能声称已从部署中删除旧选择器。不会自动进入数量适配或下一套方法。

## 文件

- `attribution_model.py`：两因素模型、普通对照及独立预测入口。
- `attribution_losses.py`：Train来源的字典类别归属对比。
- `run.py`：联合验证、配对训练、封存、来源诊断和六档正式评价。
- `config.json`：本轮固定协议。
- `runs/seed13/status.json`：当前进度；结束后`results.json`与`实验结果.md`保存结果。

```powershell
python run.py --stage validate
python run.py --stage train
```

运行所需冻结特征与基础损失复用`ShipsEar_SourceComponent_20261026`，该目录及其原H1依赖需要保留。没有哈希或新的全量质量检查；联合验证只确认梯度分工、字典更新、类别输出与H1复现。
