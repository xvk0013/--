# T1、F1M1与V1：版本对照及前端改造依据

本次只整理已有代码、封存结果及同样本预测，不修改模型、不训练、不重选权重。

## 版本身份

更符合“10月30日、Single六档总体高于Double”描述的是T1_l1_tfblocks第27轮，不是严格命名的F1M1第33轮。

| 版本 | 第一类特征 | 第二类特征 | 公共识别 |
|---|---|---|---|
| 10月30日T1，第27轮 | 固定一维散射3730维 | 长短窗可学习时频编码512维，短窗用时频分离/前置LN/FFN块 | 成员交互、门控、TabM及集合/数量读出 |
| 原F1M1，第33轮 | 同类固定一维散射3730维 | 固定长短窗二维谱散射3200维 | 相同机制家族，输入维度不同 |
| V1，续训第18轮/源累计51轮 | 与F1M1相同 | 与F1M1相同 | 与F1M1架构及参数量相同 |

T1与F1M1/V1的提取器不同；F1M1与V1之间没有增加、删除或替换模块。神经编码器有自身训练历史，三者不是等训练历史的架构消融。

## 六档Test封存成绩

单元格依次为Single / Double / 综合ACC，单位为%。

| 条件 | T1第27轮 | 原F1M1第33轮 | V1 |
|---|---|---|---|
| 原始 | 88.17 / 83.33 / 85.63 | 90.84 / 84.28 / 87.80 | 92.37 / 81.82 / 86.77 |
| 10dB | 79.01 / 73.67 / 77.54 | 78.63 / 82.95 / 83.35 | 82.82 / 81.06 / 83.47 |
| 5dB | 76.72 / 69.32 / 74.34 | 66.03 / 78.41 / 76.85 | 75.95 / 79.92 / 80.73 |
| 0dB | 74.43 / 60.42 / 68.53 | 62.98 / 67.61 / 69.44 | 65.27 / 72.54 / 73.09 |
| −5dB | 74.81 / 48.30 / 61.35 | 65.27 / 35.23 / 50.63 | 48.47 / 60.42 / 60.78 |
| −10dB | 63.74 / 40.34 / 53.14 | 71.76 / 1.14 / 32.04 | 37.79 / 37.31 / 43.67 |

F1M1和V1背景六档均100%。T1背景依次为91.95、96.55、97.70、100、100、98.85%。

T1的0→−5dB Single提高0.38pp，实际为262条Single中多正确1条，整体下降趋势较缓。
原F1M1负SNR Single回升同时Double塌缩，−10dB有510/528条Double判成Single，不作为健康抗噪曲线。
V1的Single、Double六档均单调下降，问题是Single下降速度较快及5/0/−5dB的相对差距。
V1是当前开发中的工作基准，不是每个条件都最佳；原F1M1原始综合ACC更高。

## 训练差异

| 项目 | T1第27轮所属实验 | 原F1M1 | V1 |
|---|---|---|---|
| 原始/10/5/0/−5/−10抽样概率 | 70/6/6/6/6/6 | 50/25/10/15/0/0 | 50/10/10/10/10/10 |
| 含噪Single训练视图 | 继承当时包络规则 | 正SNR使用已有Single包络 | 全档使用正式存储波形后追加AWGN |
| 初始化 | 继承S0，三个短窗块新初始化 | 公共TabM重新训练 | 继承原F1M1第33轮 |
| 公共参数训练 | 公共与完整短窗共同适配，长窗冻结 | 公共网络训练 | 公共网络继续训练20轮 |
| 选择重点 | 原始保护、负SNR单双及MB | 原始与10/0分组宏平均 | 原始保护及5/0收益 |

F1M1→V1还同时包含追加训练、学习率与选模变化，不能把全部性能差异归于某一个因素。
已有同起点C1均匀覆盖对照帮助分离波形视图作用：V1相对C1的Test Single在5/0分别+8.40/+9.92pp；
但当时Val也出现Double保护未通过。当前比较不据Test追加权重或划分选择。

## 0dB：旧T1的Single优势有多少来自数量取舍

| 指标 | T1 | V1 |
|---|---:|---:|
| 实际Single | 74.43 | 65.27 |
| 给定真实数量后的Single船型诊断 | 86.64 | 85.88 |
| Single→Double条数 | 46 | 80 |
| Single数量正确但船型错误条数 | 20 | 9 |
| Double→Single条数 | 93 | 38 |
| 给定真实数量后的Double组合诊断 | 74.81 | 78.41 |

旧T1相对V1的Single净多正确24条，来自少34条S→D、少1条S→背景、但多11条同数量船型错误。
其Double净少正确64条，其中多55条D→S、多9条组合错误。
因此不能把旧T1的所有Single优势直接解释成提取器更强，也不能通过统一压低Double得到目标曲线。

−10dB下，T1与V1的条件Single分别77.86%、69.08%，说明旧版也有值得借鉴的强噪声船型表征。
条件成绩只作诊断，不是可部署成绩或新模型保证能实现的上界。

## 与最新诊断的联系

1. 原始参考方向替换能同时救回部分Single和Double，但不证明现有含噪摘要可预测出参考。
2. 小批次校正可拟合94%以上；完整纯恢复在Train/Val恢复约37%/34%，却显著损伤识别。全向量余弦距离不适合作为独立主目标。
3. 固定P1后适配全部TabM只能部分救回，仍低于同预算原输入。该恢复器退出候选。
4. 首层混合/单路非线性残差加入上下文适配后，仍无Single与综合共同收益。停止该轮隐层补强。

因此下一步若开展额外研究，应独立标为前端结构改造，不继续接P1，不把旧神经特征冻结后重新训练TabM当成新方法：F0M0/F0M1已经做过类似冻结表示比较。

## 推荐的一次前端改造

保留V1一维散射与长窗二维谱散射，只改短窗谱散射之前的局部时频变换。

原路径：短窗log-power → 固定二维谱散射 → 8×4统计 → 公共TabM。
候选：短窗log-power → 零输出初始化的时频分离残差变换 → 固定二维谱散射 → 原统计 → 公共TabM。

借鉴T1短窗块的频率/时间分开运算和残差组织，不复制其不兼容权重，不搬入完整旧网络。
输出保持原短窗图尺寸、特征维度与类别定义。新算子从恒等起点开始，确保完整V1初始输出不变；
新增算子与全部TabM使用识别/数量监督共同训练，不使用全向量原始恢复损失。

该候选改变的是进入散射之前的实际谱结构，是部分可学习前端。
此前D1作用于散射后的局部系数，并联合局部SmoothL1恢复目标；不能将两者混称同一次实验，
也不能因位置变化就认定一定有效。

训练必须从当前短窗谱图经新算子和可导散射进入识别，不能缓存旧3200维特征后声称训练了新前端。
一维散射、长窗及其他不变部分可缓存。验证新前端梯度可穿过固定小波核，且真正更新上下文。

采用依据仍是5/0dB Single净修复、Double与综合收益及原始保持。
不要求通过降低Double来制造Single优势。若无正收益，该候选退出，回到V1并继续原定整理/新数据集工作。
