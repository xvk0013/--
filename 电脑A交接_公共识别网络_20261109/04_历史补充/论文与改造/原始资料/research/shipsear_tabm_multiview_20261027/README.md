# 双视图公共TabM：首轮机制对照

本轮研究成员输入适配与跨视图交互的先后顺序。固定录音级数据与七集合任务；A为3730维散射全局/四段统计，B为既有双频段log-power声谱分别固定汇聚为128×16后拼接126维DEMON，共4222维。全部声学变换固定，无M2、BEATs、旧数量头或旧任务权重。TabM与交互参数从相同随机起点训练。

G0直接拼接后使用官方TabM。G1在第一层增加一份所有成员共用的低秩交互。G2在相同位置、相同参数量下，将TabM已有的成员输入缩放先作用于两路原始特征，再投影并计算成员交互。输入缩放发生在混合投影之前；若只缩放交互输出，可能退化为普通公共交互的重参数化。两组交互输出零初始化，初始预测与G0一致；直接路径保留。

采用TabM 0.0.3，3层、宽度256、32成员、dropout0.15，交互维度64。每个成员独立接受集合CE和0.1权重的数量边缘监督。推理平均成员概率并选七集合argmax，最终数量由该集合确定；数量边缘不作硬路由。保持既有Train样本权重，原始/10/5/0/−5/−10 dB训练抽样30/10/10/10/20/20%，逐轮独立在线AWGN；三组使用相同波形、批次、dropout随机流与更新次数。

种子13，最多80轮，至少20轮；全部组均连续15轮未改善时共同早停。按0.5原始Val分组宏平均＋0.5五档含噪Val分组宏平均的均值选择各组唯一权重，同分看原始综合ACC。模型选择封存后再评价Test。历史H1和独立散射模型是不同结构、不同初始化的历史参照，不作为本轮受控对照。

运行验证：python run.py --validate

正式训练：python run.py

中断续训：python run.py --resume

运行状态与结果在runs/seed13。model.Recognizer接受单条或批量16kHz、5秒混合波形，输出七集合概率、集合与数量。必要验证包括特征维度/有限值、初始输出匹配、G1/G2参数量一致和交互梯度；未添加文件哈希或重复数据审计。

复用代码：既有fixed_data.py、noise_data.py、固定声谱/DEMON变换及固定散射定义。依赖源码与许可证保留于vendor。核心对照是G2对G1；G1对G0区分普通交互收益。成员分歧或训练拟合提高不能替代最终识别改善。
