# ShipsEar 类别证据交换实验

本实验保持已固定的录音级 Train/Val/Test 划分及正式评估波形，检验内部类别证据交换是否独立改善 0/1/2 目标识别。H1 作为冻结参照；实验模型的神经声学与散射特征均继承 H1，新增三个 PF/MB/RV 证据槽及共同的七集合、数量读出。正式推理只输入混合音频。

## 配对视图

从同一条 Double 索引恢复两路已经施加增益和时间包络的 Train 来源组件 `u`、`v`。配对为 `normalize(u+v)` 与 `normalize(u)`，或对称地保留 `v`。现有 Single 文件并非这条 Double 的严格移源对应。含噪配对共用一次外加 AWGN 抽样，各自按既有协议归一化；原来源录音自带的环境声仍包含在组件中。训练配对只读取 Train 组件，Val/Test 的配对仅用于训练结束后的机制诊断，正式评价始终使用原数组。

## 同预算对照

- `ordinary_pair_supervision`：原始 Train 样本与上述配对视图接受普通集合、数量和类别存在监督。
- `evidence_interchange`：结构、初始化、数据、训练轮次及标签损失量相同；其中一份普通配对读出改为交换 PF/MB/RV 中的相应证据槽，再监督合法的集合与数量。

前 3 轮为共同预热，第 4 轮起两组分化。两组均按 `0.5 × 原始 Val 综合 ACC + 0.5 × 五档含噪 Val 综合均值` 在**实际训练轮次**中选择唯一权重。第 0 轮 H1 精确重放单列为固定参照，不作为新方法权重。两组共同最多训练30轮；满15轮且两组都连续10轮未改进时按Val早停。Test 只在选模封存后评估。除了正式六档分项，还报告原始与 −10 dB 的留出录音配对交换正确率，二者不能混称。

## 版本记录

第一版随机新读出接口（`evidence_model.py`）在第 13 轮停止，记录保留在 `runs/seed13`。它属于探索性接口诊断：数量路由损伤了 Double/背景，且交换组比普通组多一份配对标签损失，不能用于交换机制的独立收益判断，未评价 Test。

修订版（`replay_evidence_model.py`）把 H1 的集合及数量对数概率拆分放进三个可交换证据槽，并以零初始化的残差读出保证第 0 轮精确重放 H1；同时修正等权普通对照。首次试跑记录在 `runs/seed13_replay_matched`，至第 9 轮停下，未评价 Test：其选模把第 0 轮也当成实验组候选，可能令两组都退回相同 H1。正式修订重跑单列第 0 轮，结果写入 `runs/seed13_trained_only_matched`。

本方法属于对既有交换干预训练思想的任务化适配。只有当它相对等权普通监督改善留出录音上的实际识别，并展现相符的交换行为，才可作为当前任务中的方法贡献。

## 本轮结果

正式对照、类别槽成分拆分及后续判断见 [实验报告.md](实验报告.md)。机器可读指标位于 `runs/seed13_trained_only_matched/results.json`，Val 槽拆分诊断位于同目录 `slot_components_val.json`。证据交换版在 −10 dB 的正式综合 ACC 为 52.57%，普通配对版为 54.39%，原 H1 为 55.42%；当前版本尚未建立识别收益。
