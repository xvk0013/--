## 结论与后续位置

本轮继续采用 ShortLocal 的长窗 8×4 汇聚。L1 的参数量降低约 20.7%，同批波形推理耗时降低约 19.3%，但在 Val 和 Test 都损失了背景及强噪声 Single 识别。Test 的 5／0 dB 背景从 98.85%／96.55% 变为 47.13%／45.98%，−10 dB Single 从 65.65% 变为 45.80%。原始综合提高 1.03 个百分点、−10 dB 综合提高 0.91 个百分点，伴随更强的 Double 倾向。在 −10 dB，Single→Double 从 60 条增至 125 条，Double→Single 从 127 条减少到 58 条。L1 评估的是长窗删除与公共输入缩小后的完整模型，其结果支持在当前搭配中保留长窗。

L2 的 Val 六档综合均值提高 0.60 个百分点，但首要的单双均衡分低 0.12 个百分点，原始 Val 综合降低 2.09 个百分点。其 Test 六档综合均值降低 0.61 个百分点，10／5 dB 综合分别降低 1.14／1.25 个百分点，−5／−10 dB Single 分别降低 3.44／2.29 个百分点。三版原始共同判对的 Test 船目标中，−10 dB 的保持率为 ShortLocal 62.92%、L2 61.64%。32×1 在 Val 负 SNR 档上的收益没有转化为对应的 Test 收益。

两个候选均使用种子 13 完整重训。L2 和 ShortLocal 的模型参数及其初始化相同；L1 根据较小输入维数重新构造公共网络。当前证据支持保留长窗，并继续用 ShortLocal 作为后续对照。下一项结构替换可针对长窗二维散射提取算子，在同一长窗谱图和输出接口上检验可学习的频率局部编码。长窗汇聚的这一次预算重分配尚未恢复原始性能，因此后续应把重点放在提取算子的价值验证上。
