# 频带时序完整训练失效核查

使用 F、B、C 封存权重和相同的完整 Val 5／0 dB 样本，只读回放。三组原始开关状态的预测与逐样本封存记录完全一致。随后在同一权重上关闭时间残差，或仅将 C 的频率坐标置零。全程没有重训、重选权重或评价 Test。

探针将长窗相邻三帧固定混合为 0.25／0.50／0.25，每组使用对应 Train 统计量。正式 B／C 则在原系数上学习零起点的差分残差，使用原汇聚的 Train 归一化和完整 TabM 的联合任务损失。两者测的是不同幅度和优化条件下的处理。

| 0 dB 平均门值 | 0.5710 | 0.5664 |

| 0 dB 长窗摘要变化中位数（按 F 标准差换算后，逐样本跨维 RMS） | 0.2518 | 0.2263 |
| 0 dB 关闭残差后预测变化数 | 30／716 | 21／716 |
| 0 dB 综合开启 → 关闭 | 64.25% → 62.43% | 63.55% → 62.71% |

同一批 0 dB 样本上，探针固定混合的长窗摘要变化以相同 F 标准差换算为 2.1623。C 仅置零频率坐标时，5 dB 有 0 条预测变化，0 dB 有 2 条变化，0 dB 综合 63.55% → 63.83%。这次回放说明新增路径已参与预测，而频率坐标在封存 C 中的实际影响很小。它没有测量删除通路后重新训练的性能。

在完整逐轮历史中，只读计算 Val 5／0 dB 平均综合的诊断峰值，F／B／C 分别为 67.46／67.25／67.60%。已有记录没有显示六档综合选模掩盖了明显的 5／0 dB 进步，保留原选模结论。
