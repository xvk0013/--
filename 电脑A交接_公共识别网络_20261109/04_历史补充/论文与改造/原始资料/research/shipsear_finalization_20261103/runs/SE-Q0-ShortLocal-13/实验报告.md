# Q0 二维短窗局部编码实验

## 替换范围

Sun–Wang 的同形状输入对照显示，平滑相邻 17 帧会降低强噪声下的 Single 保持率，并改变单双目标的数量误判。此次检验在 Q0 的二维短窗路上保留密集的帧级输入、先学局部响应再汇聚，能否将该收益转移到完整模型。 [Sun–Wang 对照（本机出处）](../../../../../../../90_本机路径.md#r403)

| 部分 | 正式 Q0 | ShortLocal |
| --- | --- | --- |
| 波形路 | 固定一维散射，3,730 维 | 同 Q0 |
| 二维长窗 | 512 ms 窗、64 ms 步长，二维散射，1,600 维 | 同 Q0 |
| 二维短窗 | 128 ms 窗、16 ms 步长，二维散射，1,600 维 | 30 ms Hann 窗、7.5 ms 步长、1,024 点 FFT。128 个 log-Mel 频带覆盖 0 至 4 kHz，每段 663 帧。局部残差卷积后，在 25 个响应通道上按 8×4 网格取均值和标准差，共 1,600 维。 |
| 识别 | 6,930 维输入，Q0 的异构特征交互和 32 成员 TabM，输出七种集合 | 同 Q0 |

短窗编码器在首次沿时间轴降采样前经过三层 3×3 卷积，汇聚后的新短窗统计使用仅由 Train 更新的批归一化。一维散射和长窗的标准化仍由 Train 原始视图拟合。新方案同时改了短窗长度、谱图表示和局部编码器，比较单位为整个短窗部分。

## 训练与评价

新 MB 划分的 Train、Val、Test 分别为 2,877、719、877 条。候选的 TabM 和短窗卷积均从构造初值训练，种子 13。训练原始档占 50%，五个含噪档各占 10%，使用原 Q0 的集合加权交叉熵、数量边缘损失、AdamW、学习率、批大小和六档 Val 排序。比较基线为同协议已完成的种子 13 完整重训。两个模型分别用 Val 封存权重，再评价同一批 Test 的同一噪声视图。

比较六档的完整集合 ACC 与 Single、Double、背景准确率，并在各自 Val 和 Test 的原始档共同判对样本上比较加噪保持率。重点看 −5、−10 dB 的 Single，以及原始到 0 dB 的综合和各数量表现。数量误判用于辨别 Single 改善是否伴随漏掉第二目标。

在工程根目录用原 CUDA 环境运行 `python -B research/shipsear_finalization_20261103/train_formal.py --short-local`。 [结构实现（本机出处）](../../../../../../../90_本机路径.md#r404) · [训练入口](../../../../../../../03_论文写作/引用资料/1494_train_formal.py) · [控制台记录（本机出处）](../../../../../../../90_本机路径.md#r405) · [解析配置](config_resolved.json)

## 成对保持率

Test 的原始档共同判对样本包括 Single 224 条、Double 405 条、背景 87 条。Val 的对应数量分别为 186、225、60 条。以下分母在各档固定，每格为 Q0 → ShortLocal。

| 集合与分组 | 0 dB | −5 dB | −10 dB |
| --- | ---: | ---: | ---: |
| Test Single | 87.50% → 90.62% | 78.12% → 85.71% | 70.09% → 71.88% |
| Test Double | 80.00% → 80.74% | 61.73% → 71.85% | 29.38% → 56.79% |
| Test 船目标合计 | 82.67% → 84.26% | 67.57% → 76.79% | 43.88% → 62.16% |
| Val Single | 87.10% → 91.94% | 72.58% → 83.33% | 68.82% → 65.59% |
| Val Double | 75.11% → 73.33% | 67.11% → 63.56% | 41.33% → 46.67% |
| Val 船目标合计 | 80.54% → 81.75% | 69.59% → 72.51% | 53.77% → 55.23% |

Single 在 0 和 −5 dB 的保持率同时改善于 Val、Test。在 −10 dB，其 Test 绝对准确率增加 0.38 个百分点，Val 减少 2.78 个百分点。该档 Test 综合增益主要来自 Double。新方案在 −5 dB 多判对 Single 24 条、Double 44 条，背景数量相同。在 −10 dB 多判对 Single 1 条、Double 110 条，背景数量相同。

## 数量误判与组合识别

每格为 Q0 → ShortLocal，统计完整 Test。

| 条件 | Single → Double | Single → 背景 | Double → Single | Double → 背景 | 数量对、组合错的 Double |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 dB | 46 → 26 | 2 → 0 | 78 → 90 | 1 → 0 | 87 → 71 |
| −5 dB | 63 → 34 | 3 → 1 | 127 → 120 | 4 → 0 | 109 → 76 |
| −10 dB | 50 → 60 | 17 → 4 | 228 → 127 | 30 → 14 | 120 → 127 |

在 −5 dB，新增的局部编码同时减少 Single 虚增第二目标和 Double 漏掉第二目标、组合判错的次数。在 −10 dB，主要收益是恢复第二目标的存在判断，数量判别准确率从 62.94% 升到 76.62%。在该档 Double 中，PF+MB 从 25.57% 升到 50.00%，MB+RV 从 21.59% 升到 61.93%，PF+RV 从 38.07% 变为 35.80%。

## 保留与后续定位

ShortLocal 可作为抗噪候选保留。Test 的 Single 六档均高于 Double，并随 SNR 恶化依次为 87.79%、85.50%、85.11%、82.82%、77.86%、65.65%。综合 ACC 也逐档下降。原始条件 Single、Double、背景分别达到 87.79%、80.49%、100%，综合 ACC 为 84.61%，距离大于 85% 的目标还差约 0.4 个百分点。Double 在 10 dB 的 81.06% 比原始高 0.57 个百分点，背景在 5 和 0 dB 分别为 98.85%、96.55%，到负 SNR 回到 100%。

本轮表明整个短窗替换能在完整 Q0 中带来明显的低 SNR 收益。由于候选同时改变短窗长度、Mel 表示、局部卷积和短窗输出归一化，各部分的独立贡献需要后续消融拆分。结果来自固定新 MB 划分、种子 13。下一步若继续，应围绕原始条件识别能力的损失检查这个短窗替换，优先比较相同 30 ms Mel 输入上卷积后的空间汇聚位置和粒度。

首次单批验证沿用了基线检查文件名。候选记录已移至独立的 short_local_smoke.json。训练完成后，两条路径均已补跑并通过单批验证，基线检查记录已恢复。新短窗卷积的参数更新和保存优化器后恢复下一步更新的检查均通过。
