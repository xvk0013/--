# T1 至正式重训的实验审计

核对范围为 2026-10-30 的短窗 T1 至 2026-11-03 的 SE-F-13／42，依据工作区与 ShipsEar 归档中可定位的配置、封存选择和结果。优先级按候选是否会改变当前论文的主张排列。当前方法的关键对照对象是双固定散射视图、公共 TabM 的显式交互和门控，以及数量—集合联合读出。表中数值为百分点，除单列外，采用原报告的 Val 5／0 dB 均值。历史采用门槛保留原样。

现有资料能确定候选是在何种适配条件下被淘汰，以及哪些正式对照尚缺。候选全程重训后的表现，以及短续训是否为单一失败原因，仍待验证。

- **T1 起点本身**。短窗三个时频块随机初始化，继承 S0，冻结长窗，短窗及公共层适配。两组共训 37 轮，候选选第 27 轮，原始背景、−10 dB Double 等未过保护。旧结构对照的封存 Test 回退第 0 轮。T1 后续作为开发参照和异构特征来源。 [T1 阶段结论](../shipsear_short_tfblocks_20261030/阶段结论.md)
- **数量头与硬路由**。10-31 在冻结 V1 的四个接口单独训练数量线性读出；11-01 成员独立数量头实际训练 15 轮，选第 3 轮，原 TabM 和集合评分继续冻结。相对 V1，Val 5／0 dB Single −4.23、Double +2.08、综合持平。此前 C1 固定权重去数量残差后，Val 5／0 dB 综合 −3.21。这些记录分别说明冻结硬路由和推理时遮挡的表现。要验证最终数量联合机制，做从头训练的 Q0 和 L0，分别去数量残差及数量辅助损失。 [数量探针（本机出处）](../../../../../90_本机路径.md#r427) · [成员数量头（本机出处）](../../../../../90_本机路径.md#r428) · [残差遮挡（本机出处）](../../../../../90_本机路径.md#r429)
- **F0／F1 × M0／M1**。公共识别网络四组随机起点训练 43 轮，F0 神经视图冻结，F1 双固定散射。F1M0 与 F1M1 的差别是显式交互和校准门，均保留数量联合读出。F1M1 相对 F1M0 的 Test 原始综合 −0.57、0 dB +1.60，使用旧的中高 SNR 日程。这是旧协议下最接近 I0 的训练对照。共同谱增益 S0／S1 也从随机公共初值训练，两组实际 30 轮。PCEN 没有越过前置筛查，未训练。 [四组对照](../shipsear_fixed_spectral_factorial_20261031/实验报告.md) · [共同谱增益（本机出处）](../../../../../90_本机路径.md#r430) · [PCEN 定位（本机出处）](../../../../../90_本机路径.md#r431)

## 正式实验的先后关系

先决定当前完整模型结构是否冻结。若论文希望接纳优先级 1 的结构替代，先按现有单阶段协议比较候选和现有 F，再锁定主模型。后续从锁定结构派生正式消融。若保留现有 F，则直接复用已完成的 SE-F-13／42，核心对照按同一训练日程执行一次。同一个模型和协议已经完成的结果直接复用。若替换主模型，只重新计算依赖该变化的对照；训练协议一并变更时，重新核对每个结果的可比性。

T0／MLP／I0 检验完整后端改造、基础分类器与显式交互。A0／G0 对应乘积运算和自适应门。Q0／L0 对应数量残差和辅助监督。E1／E2 与 I0 对应两路固定视图的互补。历史落选候选的复验与这些正式对照承担不同问题。 [已登记的对照矩阵](统一收尾路线.md)
