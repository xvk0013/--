## 完整模型与屏蔽组的配对变化

去 1D、去 2D 后，Test 六档综合 ACC 均下降，六档平均分别下降 3.04 和 5.59 个百分点，−10 dB 分别下降 4.33 和 9.01 个百分点。按同一批样本统计，两条分支的影响集中在不同错误上。

| Test 条件 | 对照 | 正确 Single | 正确 Double | 主要数量误判 |
| --- | --- | ---: | ---: | --- |
| 0 dB 与 −5 dB 合计 | 完整 GN → 去 1D | 405 → 387 | 691 → 663 | Double → Single 169 → 213 |
| 0 dB 与 −5 dB 合计 | 完整 GN → 去 2D | 405 → 332 | 691 → 663 | Single → Double 80 → 149 |
| −10 dB | 完整 GN → 去 1D | 172 → 151 | 244 → 227 | Single → Double 55 → 62 |
| −10 dB | 完整 GN → 去 2D | 172 → 154 | 244 → 183 | Double → Single 155 → 205 |

限制在两版原始档都判对的样本上，−10 dB 去 1D 组的 Single 正确保留数为 161 → 139（224 条），去 2D 组的 Double 正确保留数为 208 → 158（397 条）。两组从头训练的结果对应整条输入路径及其参与的交互。整条交互残差由双路 CAT 对照检验，乘积算子由 GN-ADD 单独检验。 [全部配对数据（本机出处）](../../../../../90_本机路径.md#r415)

此前 GN-1D／GN-2D 使用裁剪后的标准 TabM，首层宽度及构造初值与本轮的全宽屏蔽组不同。保留两套对照，分别回答普通拼接下的输入增量和完整模型去掉一路的总影响。 [标准 TabM 单路对照](ShortLocal-GN单路消融汇总.md)
