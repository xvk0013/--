## 封存模型的 Val 回放

各样本先在 32 个成员上求均值，再对样本取中位数。坐标能量占比是四个最大平方值之和除以 64 维平方和。RMS 比为门控后的交互残差相对直通项的幅度。

| 条件 | Q0 投影输入前四占比 | 候选变换前 → 投影输入前四占比 | 交互／直通 RMS 比，Q0 → 候选 |
| --- | ---: | ---: | ---: |
| 原始 | 61.37% | 56.60% → 29.01% | 0.337 → 0.079 |
| 10 dB | 63.69% | 55.77% → 28.61% | 0.403 → 0.089 |
| 5 dB | 66.83% | 54.72% → 28.09% | 0.475 → 0.132 |
| 0 dB | 65.99% | 53.68% → 27.33% | 0.532 → 0.200 |
| −5 dB | 62.47% | 53.51% → 27.05% | 0.554 → 0.253 |
| −10 dB | 60.32% | 53.64% → 27.04% | 0.566 → 0.279 |

回放重现了两组全部 Val 预测。候选变换前后 RMS 的最大相对误差低于 0.15%。投影前幅度匹配通过，但共同训练后的投影与门控使交互残差相对直通明显减弱。

## Test 错误与结论

| 条件 | Single→Double，Q0 → 候选 | Double→Single，Q0 → 候选 | Double 组合错判，Q0 → 候选 | 纠正／损坏 |
| --- | ---: | ---: | ---: | ---: |
| 5 dB | 41 → 46 | 53 → 58 | 74 → 85 | 30／50 |
| 0 dB | 64 → 64 | 58 → 49 | 110 → 126 | 66／76 |

5／0 dB 分别净少对 20、10 条。0 dB 的 MB+RV 被判为 PF+RV 的样本从 39 增至 87 条。−10 dB 的 Single 从 36.26% 升到 54.96%，伴随 Double 从 48.48% 降到 29.36%，综合下降到 44.01%。候选出现更多 Single 领先档位，但损失了组合正确率和六档中的多档综合表现。保留 Q0，结束本次幂归一化方案。 [候选逐档结果](runs/SE-Q0-Power-13/results.json)
