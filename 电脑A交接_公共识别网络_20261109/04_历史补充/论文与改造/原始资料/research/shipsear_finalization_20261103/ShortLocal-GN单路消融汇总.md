# ShortLocal-GN 单路消融汇总

以已完成的双路 GN-CAT 为参照。GN-1D 只用 3,730 维一维波形散射，GN-2D 只用 1,600 维二维长窗散射与 1,600 维短窗 log-Mel GN 编码。三组使用三块、宽度 256、32 成员的标准 TabM 和相同的七集合与数量边际监督。单路按实际输入宽度构造首层，因此表中同时报告参数量。

两组都用种子 13 从模型构造初值训练。三组的录音划分、噪声配置和六档 Val 排序相同，共同轮次的训练采样计数已核对。单路在六档短测中提取的原始特征与双路对应部分逐值一致，从 Train 拟合的保留特征统计亦已核对。六档 Val 和 Test 的样本编号、标签与交汇条件逐条对齐。

## 增量与错判

| Test 条件 | CAT 相对 1D 综合差（百分点） | CAT 相对 2D 综合差（百分点） | Double → Single（1D／2D／CAT） | Single → Double（1D／2D／CAT） |
| --- | ---: | ---: | ---: | ---: |
| 原始 | +4.33 | +0.68 | 40／28／45 | 39／19／12 |
| 10 dB | +4.10 | +2.96 | 46／25／47 | 45／65／25 |
| 5 dB | +4.33 | +1.82 | 51／19／62 | 48／75／25 |
| 0 dB | +6.73 | -1.37 | 72／23／85 | 65／76／25 |
| −5 dB | +5.93 | -1.71 | 107／31／121 | 80／105／37 |
| −10 dB | +8.55 | +0.68 | 225／29／153 | 57／170／62 |

相对 GN-1D，双路 CAT 的六档 Test 综合均值提高 5.66 个百分点，各档均提高。在 −10 dB，Double 从 32.20% 提高到 45.27%，Double 被判成 Single 的次数由 225 降至 153。

相对 GN-2D，双路 CAT 的六档 Test 综合均值提高 0.51 个百分点，Val 单双均衡分提高 3.88 个百分点。二维单路在 0 和 −5 dB 的综合 ACC 更高，且六档 Double 均较高。加入一维特征后，−10 dB 的 Single 从 25.95% 升至 61.07%，Single 被判成 Double 从 170 降到 62。该档 Double 从 61.93% 变为 45.27%，表明标准拼接在保住 Single 时牺牲了二维单路的一部分 Double 优势。

两个单路结果支持当前结构中两种输入承担不同识别作用。论文可同时展示整体准确率、Single／Double 与数量错判，说明互补在哪些条件下出现。这组对照基于种子 13，输入宽度和首层参数量随单路裁减而改变，结论对应所测试的三种完整结构。完整 ShortLocal-GN 继续作为主线，双路 CAT 用于验证输入分支的作用。
