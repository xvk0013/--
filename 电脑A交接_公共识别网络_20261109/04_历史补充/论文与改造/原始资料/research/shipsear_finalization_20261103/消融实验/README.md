## 4. 投稿前证据核查

**外部对照的比较口径。** 核对了完整 GN 与四个外部模型的解析配置和逐样本预测。各组使用同一新 MB 数据、训练加噪比例及评价噪声种子，Val 和 Test 各六档的编号、标签与交汇条件一致。TResNet-LA 与 Sun–Wang 原任务均为多目标，ShuffleFAC 和 RCMoE 属于适配的水声识别骨干。原论文设置、适配后的七集合读出、模型各自的优化设置和 Val 选择过程需要分别披露。TResNet-LA 的非目标干扰研究与这里的附加高斯噪声采用不同条件。 [新 MB 外部对照与配置](../../../../../../03_论文写作/引用资料/1504_README.md) · [TResNet-LA 原论文](https://www.sciencedirect.com/science/article/pii/S0957417425027393) · [Sun–Wang 原论文](https://pubmed.ncbi.nlm.nih.gov/35364907/)

| 同划分 Test | 六档综合均值 | −10 dB 综合 | −10 dB Single | −10 dB Double | −10 dB 背景 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 完整 GN | 75.56% | 57.35% | 65.65% | 46.21% | 100.00% |
| TResNet-LA | 66.88% | 49.83% | 23.28% | 65.34% | 35.63% |
| Sun–Wang CNN | 60.87% | 51.65% | 64.12% | 37.69% | 98.85% |
| ShuffleFAC-32 | 70.22% | 49.14% | 50.00% | 40.34% | 100.00% |
| RCMoE | 54.33% | 31.24% | 40.84% | 20.64% | 66.67% |

−10 dB 的 TResNet-LA 比完整 GN 多判对 101 条 Double，同时把 199 条 Single 判成 Double，完整 GN 为 55 条。外部比较同时呈现完整集合命中和双向数量错判。旧外部汇总中的自研参照是 Q0，本节采用当前完整 GN 的封存结果。 [外部模型六档结果（本机出处）](../../../../../../90_本机路径.md#r440) · [TResNet-LA 本地适配报告（本机出处）](../../../../../../90_本机路径.md#r388)

**录音隔离与敏感性。** 根据 `DATA_INDEX.csv` 的两个源录音字段，Train、Val、Test 分别涉及 37、13、10 份录音，录音 ID 两两无交集。MB 的 Train／Val 交换由原验证结果引导，Test 的 877 条波形未变。此划分和 Test 成绩已参与模型开发，应按固定录音级开发基准报告。 [划分与交换记录（本机出处）](../../../../../../90_本机路径.md#r401) · [数据索引（本机出处）](../../../../../../90_本机路径.md#r408) · [评估协议](../正式实验协议.md)

逐一排除某份 Test 录音及其参与的所有样本后，用原封存预测复算五个加噪档平均 ACC 差。GN 对 GN-ADD 的差值范围为 +0.50 至 +3.52 个百分点。GN 对 CAT 的差值范围为 −1.11 至 +2.44 个百分点，排除 79 号录音关联的 371 条样本时差值反转。该分析用于描述对源录音构成的敏感性。 [正式结果与配对记录](../../../../../../03_论文写作/自研参照/报告/ShortLocal-GN正式消融报告.md)

**方法归属。** 项目使用 TabM 0.0.3 的原有主干及成员集成。首层门控乘积残差来自项目早期 T1／V1 架构，在 ShortLocal-GN 中与一维波形散射、长窗二维散射、短窗 log-Mel CNN 配合。七集合直接读出与数量边际辅助损失属于任务适配。逐元素低秩双线性融合及乘积残差都有公开先例。当前可主张的是特定水声任务上的首层融合适配及其受控比较。论文应标明 TabM、散射实现和相关融合方法的来源，发布代码时按适用许可证保留归属。 [本地依赖来源](../../../../../../03_论文写作/引用资料/1493_README.md) · [当前首层实现](../../../../../../03_论文写作/引用资料/1492_model.py) · [TabM](https://proceedings.iclr.cc/paper_files/paper/2025/hash/c1ba41c694834aeef91ae161711d4939-Abstract-Conference.html) · [低秩双线性融合](https://openreview.net/pdf?id=r1rhWnZkg) · [多模态乘积残差](https://proceedings.neurips.cc/paper/2016/hash/9b04d152845ec0a378394003c96da594-Abstract.html) · [出版伦理](https://www.elsevier.com/about/policies-and-standards/publishing-ethics)

## 5. 下一阶段的优先顺序

1. 冻结当前 ShortLocal-GN 的方法定义和原论文、代码的归属。验证在低信噪比下能否减少漏判第二目标、提高双船完整组合命中，同时控制 Single→Double 与背景误报。
2. 先复核 TResNet-LA 和 Sun–Wang 的原实现与本地适配。以原论文、作者代码和预定 Val 预算作为复现依据，逐档呈现综合、Single、Double、背景及配对错判。ShuffleFAC-32 同时提供轻量参考。
3. 预登记一套未参与当前模型选择的源录音级确认评测，优先复验完整 GN、GN-ADD 和经复核的任务匹配强基线。按录音组织不确定性分析，另行记录训练种子效应。确认结果决定论文能否把首层适配作为核心方法贡献。

短窗路径、短窗归一化和乘积／加法复用现有对照。**GN-GLOBAL** 改列条件项，论文若单独主张动态门控有增益，再保持双路和乘积不变，用全局可学习标量替换门控网络。
