# 新窗口交接｜当前进度与核心创新难点

2026-11-08。当前停在**已有研究参照已冻结，论文核心方法需要重新论证**的阶段。用户会在新窗口补充具体问题。本说明提供背景、已完成的证据及其适用范围。

## 1. 研究任务与当前参照

研究的是低信噪比下的单通道水声目标集合识别。输入为 5 秒、16 kHz 波形，输出背景、单船型或由两种不同船型组成的双船型集合。ShipsEar 和 DeepShip PTT 分别使用三种船型、七个集合。DeepShip PTT 的三种船型是 Passenger ship、Tanker、Tug，每个片段的同时目标数仍为 0／1／2。数据采用源录音级划分、Bellhop E99 信道和 C0／C1／C2 交汇条件，另用六档附加噪声视图评估。

ShortLocal-GN 的输入分两路。一维波形散射给出 3,730 维统计，时频路由长窗二维谱散射和短窗 log-Mel 局部 CNN 各给出 1,600 维。短窗卷积内用 GroupNorm。两路送入公共 TabM，首层带门控乘积残差，后续 32 个成员输出七集合概率并取均值，预测集合确定数量。数量边际损失用于训练。Q0 与 GN 的主要差别在短窗特征路径。

## 2. 这个窗口推进到了哪里

1. **把历史训练和正式结果分开。** 早期从 BEATs、M2 和神经—散射异构方案转到公共 TabM。T1 保留神经时频路，F1M1 改成双固定散射，V1 和 P50 属于同一结构家族的续训链。后续完整重训单独登记，Q0 和 ShortLocal-GN 以各自的构造初值训练结果为准。P50 的历史收益不能仅归给选模规则。 [阶段模型与训练沿革](../03_论文写作/技术初稿交接_20261108.md)
2. **完成外部对比。** ShipsEar 新 MB 已跑 ShuffleFAC-32、TResNet-LA、Sun–Wang CNN、RCMoE 四组。DeepShip PTT 已跑 ShuffleFAC-32 和 TResNet-LA。各数据集内统一录音划分、目标集合与六档评价视图，实际前端、输出和训练预算按本地适配记录。自研结构变化后，同数据与评价协议的外部结果可继续用。 [外部对比交接包](../03_论文写作/外部对比/00_开始这里.md)
3. **完成 ShipsEar GN 正式消融。** 四组是屏蔽 1D、屏蔽 2D、双路 CAT、等参数 GN-ADD。另有标准 TabM 单路、ShortLocal-BN／GN、长窗 L1–L4 和同段双线性替换等辅助对照。L1–L4 的参照是 ShortLocal-BN。GN-GLOBAL 留作动态门控的条件项，DeepShip PTT 的 CAT／ADD 尚未完成。 [正式与辅助消融索引](论文与改造/原始资料/research/shipsear_finalization_20261103/消融实验/README.md) · [PTT 消融登记](论文与改造/原始资料/DeepShip执行目录/07_论文实验/02_模块消融/README.md)
4. **完成冻结与写作移交。** GN 快照和第 29 轮权重已留档。ShipsEar Q0、GN 和 DeepShip PTT Q0 已集中到一个 ZIP，三套均从解压目录通过推理检查。技术初稿可先写任务、信道、数据构建、训练和评价。Q0、GN 及 PTT Q0 按版本引用，核心机制和最终自研结果行留待定稿。 [论文技术写作交接](../03_论文写作/技术初稿交接_20261108.md) · [三套模型 ZIP（本机出处）](../90_本机路径.md#r001)

## 3. 为什么还要重新讨论核心创新

- **现有消融支持双路输入，首层交互的独立收益较小。** 屏蔽 1D、2D 后，六档综合均值分别下降 3.04、5.59 个百分点。这包含移除输入及其参与的交互。完整 GN 比 CAT 的五档加噪均值高 1.48 个百分点，CAT 在原始档高 0.80 个百分点。与等参数 GN-ADD 相比，完整 GN 的五档加噪均值高约 1.00 个百分点，−10 dB 净多判对 14 条完整双船组合，Double→Single 从 181 条降到 155 条。现有对照支持当前划分上的乘积算子收益，动态门控的作用尚未单独隔离。 [正式消融与配对记录](../03_论文写作/自研参照/报告/ShortLocal-GN正式消融报告.md)
- **方法归属与创新强度需要分开。** 主干、成员缩放与集成沿用 TabM。项目实际改动是首层两路投影、按样本和成员调节的乘积残差，以及集合任务接口。低秩乘积融合和乘积残差都有公开先例。已有证据可以支持有来源的任务适配，但要把它作为高水平期刊的核心贡献，还需要讲清相对最接近方法的实质区别和针对的科学问题。 [方法归属与相关先例](论文与改造/原始资料/research/shipsear_finalization_20261103/消融实验/README.md#4-投稿前证据核查)
- **低信噪比仍有具体难点。** GN 在 −10 dB 的 Single／Double 为 65.65%／46.21%。同划分下，TResNet-LA 的 Double 达到 65.34%，同时把 199 条 Single 判成 Double，GN 为 55 条。新方法若针对第二船型漏检，评价要同时记录完整双船组合、双向数量错判和背景误报。外部结果按各方法的实际任务适配引用。 [同划分外部结果与错误核查](论文与改造/原始资料/research/shipsear_finalization_20261103/消融实验/README.md#4-投稿前证据核查)
- **稳定性证据目前受录音构成限制。** ShipsEar 当前三个集合的源录音互斥。Test 的 877 条片段来自 10 份源录音，且既有 Test 成绩曾用于研发判断。用封存预测逐一排除某份源录音及其混合样本后，GN 对 ADD 的加噪差值仍为正，GN 对 CAT 有一次反转。正式 GN 消融对应种子 13。后续若主张跨录音稳定收益，应另设未参与定型的录音级确认。 [划分、逐录音敏感性与协议](论文与改造/原始资料/research/shipsear_finalization_20261103/消融实验/README.md#4-投稿前证据核查)
- **已有探索须按证据类型复用。** 源干预、噪声与真实加源的配对、冻结探针、特征恢复、判别接口和时段交互都已有记录。部分是短续训或诊断，部分已经从初值完整训练。同段双线性替换已有正式运行。后续评估相似思路时，先核对它是否改变了实际机制和验证条件。 [历史失败证据矩阵](论文与改造/原始资料/research/innovation_failure_audit_20261026/历史失败证据矩阵.md) · [T1 以来训练审计](论文与改造/原始资料/research/shipsear_finalization_20261103/T1至今训练审计与复验优先级.md)

## 4. 新窗口接续的位置

当前的问题与框架可以先写成“低信噪比水声目标集合识别”和“双路声学表征、公共集合判别”。**核心机制待重新选择。** 讨论可以从一个可观察的错误出发，明确已有方法为什么难以解决、候选机制带来了什么变化，以及什么结果会推翻假设。现有 GN 用作固定对照，首层交互和 TabM 都可按新假设重新审视。核心主张明确后，再决定具体更新哪些结构和实验。数据与外部协议一致时复用已有结果，DeepShip 的最终结构训练与关键消融随后安排。 [当前收尾路线](论文与改造/原始资料/research/shipsear_finalization_20261103/统一收尾路线.md)
