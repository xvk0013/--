# 接口诊断结论与下一步主线

六组读出均完成40轮，耗时5.17分钟。V1及提取器冻结，仅新诊断读出训练。正式Val四档及受控配对十二视图的V1概率均精确重放，Test未参与。本文件依据results.json与保存的Val NPZ复核，不是新主模型正式Test性能。

## 1. 下一步优先改公共识别后段

保留一维散射、长短窗二维散射、原V1标定以及首块成员交互。下一处有正证据支持的改造接口是：首块融合表示→后两公共块→最终七集合/数量双读出。

| Val 0dB受控配对 | 原V1 | 首块后MLP | 末层后MLP |
| --- | ---: | ---: | ---: |
| Single | 67.82% | 68.75% | 65.74% |
| 等强Double | 50.93% | 56.94% | 59.95% |
| 弱6dB Double | 34.49% | 39.81% | 41.67% |
| 等强配对两端均正确 | 37.04% | 43.06% | 43.29% |
| 弱源配对两端均正确 | 21.76% | 27.55% | 26.62% |

首块MLP提供了三类输入共同改善的开发线索，既改善Single，也没有以压低Double换取Single。末层MLP则说明后层仍有可以利用的组合信息，不宜把后两块简单描述为冗余或全面破坏信息。

首块与末层维度均为32×256，成员完整保留；同类探针参数量、初始化、训练视图、更新预算和Val规则一致。0dB下，首块→末层在线性、MLP两家族中Single均减少3.01个百分点；MLP的等强Double增加3.01个百分点，弱Double增加1.85个百分点。这一取舍已经出现在公共隐藏表示的可读性中，不只存在于末端数量残差。

## 2. 直接绕过公共变换、读取6930维摘要不合适

摘要MLP在Val0dB Single为70.83%，但等强/弱Double为40.28%/26.85%。它没有形成整体替代收益。

| 0dB同来源检查 | Train拟合缓存 | Train独立新噪声 | Val新录音 |
| --- | ---: | ---: | ---: |
| 摘要MLP Single | 100.00% | 84.09% | 70.83% |
| 摘要MLP等强Double | 100.00% | 89.93% | 40.28% |
| 摘要MLP弱Double | 100.00% | 71.47% | 26.85% |
| 首块MLP Single | 88.66% | 83.16% | 68.75% |
| 首块MLP等强Double | 96.99% | 95.60% | 56.94% |
| 首块MLP弱Double | 86.17% | 78.59% | 39.81% |

摘要的固定缓存拟合100%不能当成特征已充分、已可泛化的证明。首块表示对于新噪声的组合读出更加稳定，因此保留首块有明确依据。Train新噪声到Val仍有很大差距，后续必须以录音隔离的Val和正式评价判断改造，不能用Train上能拟合为采用依据。

## 3. Single缓降尚未解决

所有探针使用同一源V1原始正确队列。0dB Single该队列的保持率：V1为79.78%，首块MLP也为79.78%，末层MLP为77.05%。因此首块MLP的Single小幅净增并非已经提高了该固定队列的抗噪保持，不能宣称Single缓降机制已经成立。

首块MLP四档Single为82.41/80.09/76.85/68.75，等强Double为64.81/59.72/58.56/56.94。曲线及排序符合当前期望，但它仍是新配对分布上的诊断读出，不能直接替代正式V1的六档成绩或归为结构因果收益。

## 4. 下一轮正式替换的范围

建议第一候选为：保留原双散射输入和TabM首块，将后两公共块及末端双读出作为一个整体接口，替换为较浅的完整七集合读出。首轮不新增Single专用头，不增加统一Single偏置，不修改声学提取器，不再附加输出恢复器。

对照为原完整V1的匹配适配；候选与对照统一使用正式Train2880/Val716、原在线噪声协议、损失预算、种子13和训练预算，并完成相关接口适配。受控配对仅用作辅助诊断，不把本轮新探针的配对训练优势冒充架构收益，也不把其权重直接拼接后当成正式验证。

判断同时看原始识别保持、5/0dB Single、等强Double、背景、综合ACC及固定队列；若只是Single/Double互换错误则不采用。正式Test遵守预定封存选择后的统一评价，不因Test改选权重。

如果较浅识别段能在正式数据上继承联合收益，再检查是否保留少量深层变换作为必要补充。若不能，先利用本轮首块/末层的同容量证据检查第二块输出及局部路径，而不是立即宣称前端完备或推翻所有提取器。

以上为下一步建议，尚未修改主模型或启动正式替换训练。
