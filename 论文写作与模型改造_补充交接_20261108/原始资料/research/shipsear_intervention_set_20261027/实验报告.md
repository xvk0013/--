# ShipsEar 类别证据交换实验报告

## 要验证的问题

把 PF、MB、RV 的判别证据放入可交换的类别槽：训练时用同一条 Double 的完整混合与移除其中一类后的混合构成配对，交换指定类别槽，要求模型输出相应的合法目标集合。推理时只输入待识别音频，不需要源音频或标签。本轮检验交换训练相对同数据、同结构、同监督量的普通训练，能否改善未见录音及低信噪比识别。

## 固定条件与对照

使用既定录音级 Train／Val／Test 划分与正式评价波形。两组都冻结 H1 声学与散射主体；三个类别槽及集合、数量读出分别训练，新增可训练参数均为 120,411。类别槽初始时精确重放 H1 的集合及数量输出。两组使用同一随机种子 13、配对生成、原始与五档含噪增强、优化器设置及训练预算；第 4 轮起，交换组将一份普通配对监督换成类别槽交换监督。两组按相同验证集综合规则选权重：普通组第 2 轮，交换组第 6 轮。共同训练至第 16 轮早停，正式 Test 在权重选定后评价一次。训练用配对只由 Train 的来源组件生成，Val／Test 配对只用于机制诊断。

普通组所选权重处于共同预热阶段，尚未接受分化后的额外普通配对项。因此 Test 表比较的是**两套训练规则各自按 Val 选中的模型**，不能把全部差异都解释为交换损失本身。同一轮的 Val 记录也保留于 `history.json`，用于检查训练轨迹。

来源组件已包含原始录音中的环境声；移除一类后重新做既定 RMS 归一化。因此这里验证的是**录音成分干预与集合判别的一致性**，不是从混合波形中唯一分离纯净船声。第 0 轮冻结 H1 另列参照，不参与新模型选权重。前两次探索试跑在修正对照损失及选模规则后停于 Val，没有评价 Test。

## 正式识别结果

Test 共 877 条。综合 ACC 如下，百分数；H1 为实验前已保留的冻结参照。

| 条件 | H1 | 普通配对监督 | 类别证据交换 |
|---|---:|---:|---:|
| 原始 | 83.69 | 83.81 | 83.81 |
| 10 dB | 77.19 | 77.54 | 78.22 |
| 5 dB | 75.37 | 75.83 | 75.71 |
| 0 dB | 72.98 | 73.43 | 71.95 |
| −5 dB | 67.96 | 67.96 | 67.05 |
| −10 dB | 55.42 | 54.39 | 52.57 |

| Test 条件与版本 | Single | Double | 背景 | Single→Double 误判 |
|---|---:|---:|---:|---:|
| 原始 · H1 | 81.30 | 82.20 | 100.00 | 36 |
| 原始 · 普通 | 82.06 | 82.01 | 100.00 | 34 |
| 原始 · 交换 | 78.63 | 83.71 | 100.00 | 45 |
| −10 dB · H1 | 38.93 | 56.25 | 100.00 | 118 |
| −10 dB · 普通 | 43.51 | 52.27 | 100.00 | 101 |
| −10 dB · 交换 | 39.69 | 51.14 | 100.00 | 125 |

交换训练在原始条件下将部分判别从 Single 转向 Double，而没有增加综合准确率；−10 dB 下 Single、Double 和综合 ACC 均低于普通对照。按各自选中权重计算，Val 的 −10 dB Single 由 58.22% 变为 52.58%，Single→Double 由 39 条增至 66 条。即使直接比较第 6 轮的两组 Val，交换组 −10 dB Single 52.58%，普通组 61.50%。该变化不是只出现在 Test 上。

## 交换机制诊断

以下在 Val 的 144 条 Double 配对上进行，**不属于正式识别 ACC**。“加目标”指从移源视图交换回被移除类的证据后得到原 Double 标签；“移除目标”是反向操作。

| 条件与版本 | 完整槽：加／移除正确数 | 只交换新学状态：加／移除正确数 |
|---|---:|---:|
| 原始 · 普通 | 6／55 | 4／19 |
| 原始 · 交换 | 34／77 | 8／15 |
| −10 dB · 普通 | 34／27 | 21／16 |
| −10 dB · 交换 | 49／50 | 40／40 |

−10 dB 下，新学状态本身对目标类别交换有可测作用；原始条件下，完整槽的收益更多依赖它与冻结 H1 先验的共同作用。当前完整槽同时携带按类别分配的 H1 七集合先验、均分的 H1 数量先验和新状态，不能把完整槽的交换正确率全部归因于学出的类别声学证据。

进一步检查**不应改变标签的槽**：在同一配对中，保留的船型在两种波形中相同，第三类在两种波形中都不存在。仅交换这两类的新学状态，理想情况下不应改变识别。−10 dB 的 Val 配对中，交换训练模型对“第三类不存在”槽的交换使 30／144 个 Single 预测改变，其中 10 个原本正确的预测变错；普通组对应为 3／144、0 个。对“共同保留船型”槽，交换组使 28／144 个 Single 预测改变，普通组为 4／144。说明当前状态虽对指定类交换敏感，也携带了非指定类别或全局数量信息。

## 结论与下一轮门槛

这版方法产生了可测的内部交换响应，但**尚未证明该响应改善最终识别，也不能将其作为已经成立的核心方法创新**。主要矛盾是类别槽没有保持类别专属作用，交换训练进一步增加虚假第二目标。

下一轮仍沿类别证据交换主线，只处理这一处结构问题：把可交换的新学类别状态与冻结 H1 的全局数量、集合先验分清，并对“共同存在／共同不存在”的类别槽加入输出不变约束。先在 Val 检查两项机制是否同时满足：指定类交换仍能改变目标集合，未变化类交换不再改坏原判断；再检查正式 Val 的 Single→Double、综合 ACC 和 −10 dB Single。若这三项不能同步改善，就停止该接口，不再靠加大交换损失或调 Test 阈值补救。改造完成并锁定选择规则后，再进行下一次正式评价。

目前所有改造都以同一批录音和同一个 Test 作过方向判断；论文中的最终泛化主张还需在冻结结构后由独立录音级评价支撑。
