# 判别接口审查：哪些信息能够改变最终船型判断

日期：2026-10-26。只读静态审查与保存预测的固定权重功能诊断；未训练、未改变模型、未运行GPU。不将功能切换结果称作重训消融。

## 1. 代码中神经证据实际承担什么职责

核对[MemberEvidenceIntegration源码](D:/LSJ/Code/UART/shipsear/ShipsEar_CompactEnsemble_20261023/final_model.py)与[当前迁回模型](D:/LSJ/Code/UART/shipsear/ShipsEar_HeterogeneousTransfer_20261025/transfer_model.py)：

- 神经hidden输入基础数量头，并生成TabM成员先验和成员评分中的神经描述。
- TabM提供32成员各自的七集合概率。
- 背景用神经先验得到的一套权重；Single三个类别共同使用一套成员权重；Double三个组合共同使用另一套成员权重。
- `conditional/deviation/entropy`参与计算成员权重，但没有直接加成最终类别logit。
- 环境解耦新增的七集合`semantic_logits`是辅助训练/诊断输出，最终船型分数没有直接使用这组logit。
- 数量修正MLP读取基础数量概率、TabM成员平均和集成概率；预测数量硬性选择背景、Single或Double词表。

因此，神经hidden可以改变数量路由和成员选择，但不能任意产生独立于TabM的新最终船型logit。这是一项具体接口限制；不等于神经分支完全无用。

## 2. 凸组合限制的精确范围

设在同一个Single或Double组G内，第m个成员给类别c的原始七集合概率为p[m,c]。最终未全局归一化分数为：

```text
s[c] = sum_m alpha_G[m] * p[m,c]
alpha_G[m] >= 0, sum_m alpha_G[m] = 1
```

同一G内的三个类别使用相同alpha。全局七集合再除以同一正归一化常数，所以不改变同组内排序。

对同组真实类别t与竞争类别d：

```text
s[t] - s[d] = sum_m alpha_G[m] * (p[m,t] - p[m,d])
```

若所有32成员都满足p[m,d] > p[m,t]，则任意共同非负权重仍有s[d] > s[t]，神经hidden再好也不能通过这套成员加权把t排到d前面。

若部分成员支持t，成员选择可能纠错；但“每个竞争类别分别存在一个支持t的成员”并不足够。必须存在同一组alpha同时满足对所有d≠t的差分为正。例如两个成员概率为[t=.2,d1=.8,d2=0]和[t=.2,d1=0,d2=.8]，t分别能战胜一个竞争者，却不可能在任何凸组合中成为第一。

这个可行性条件只表示权重空间存在可能；实际先验/共享评分网络仍需学会对应alpha，不能由数学可行性保证泛化收益。Softmax严格正权重的闭包为单纯形，边界选择可以逼近，但不能把某一有限训练评分视为所有可行权重的充分搜索。

**不能外推到全七集合共享凸包。** 背景、Single、Double的权重不同，因此对跨数量组的类别，以上“同一alpha加权差分”推导不成立。代码也不是七个候选分别使用七套权重；它是三个数量词表的权重，其中Single/Double各套内共享。

保存的环境实验NPZ不含32成员原始概率，故本轮没有统计现有错误中有多少满足“共同竞争类支配”。结构上存在上界，不等于已经证明历次失败全部由此引起。

## 3. 固定权重的数量/词表功能切换

读取环境解耦实验E0/E1/E2/E3的Val原始及−10dB NPZ，使用相同`log_prob`分别计算：

1. 保存的修正数量`log_count`硬路由。
2. 基础数量`base_log_count`硬路由，等于本次功能诊断中旁路17维修正MLP。
3. 七集合`log_prob`直接argmax，不使用数量词表。

全部8份保存预测与第一种路由逐样本复现，差异数均0。未使用真实数量选词表。

|---|---|---:|---:|---:|
|E0继续训练|原始|70.11%|75.28%|68.30%|
|E0继续训练|−10dB|52.65%|43.02%|48.32%|

以E2说明删数量MLP的代价：原始综合75.42%高于70.39%，但−10dB综合从52.93%降至40.22%；其中Single从52.11%降至0.94%，Double从50.00%升至61.11%。该旁路改变了两类取舍，没有解除数量瓶颈。

E2−10dB旁路修正后，相对保存预测救回50个样本条件、误伤141个；原始条件救回57个、误伤21个。只看原始改善会漏掉低SNR损失。

七类直接argmax在两种条件、四个版本中均低于对应修正数量硬路由。现有训练包含条件船型监督，跨数量词表分数也不必已校准；直接关硬路由不能代表重新设计并训练联合集合判别后的性能。

## 4. 删除或替换的优先级判断

|对象|当前证据|可以做的结论|
|---|---|---|
|训练专用环境头/重建器|本来不进入部署预测|最终导出可不计算或不携带，但删它们不能带来现模型识别涨点|
|公共成员集成接口|同组类别受共同凸组合限制，神经语义无直接类别输出|是职责和信息流明确的潜在替换口；不等于它无贡献，也不等于简单删除会更好|
|17维数量修正MLP|原始有误伤，同时显著救回低SNR Single|不应直接删除；是否替换需保留低SNR救回并控制原始误伤|
|硬数量词表|直接关闭后本轮所有对应综合下降|不应通过开关直接移除；新联合接口需要相应训练，不能用未适配argmax代替|
|M2/DEMON/散射TabM|本轮未做相应功能诊断或重训对照|不能据此次创新失败宣布其中某部分冗余|

删除的合理依据是消除重复职责、错误瓶颈或已无贡献计算。不能先人为削弱强基线，再以新模块恢复损失作为核心机制胜出的证据。若替换成员集成，应共同保留原完整模型、相同输入的基础读出和新方法，比较对应识别错误及整体损失。

## 5. 本轮能解释的失败与不能解释的部分

交换重建被学会，不自动意味着能产生新的最终船型证据；辅助语义七集合头的进步也可能未直接进入类别输出。当前结构确实限制了“更好的神经类别表示”向最终类别排序的表达路径。

但没有成员支配错误的统计，不能把环境解耦、CUMI、目标移源等所有历史候选无收益归于同一接口。训练约束是否合适、表征是否真正跨录音改善、数量监督取舍仍是不同问题。当前最明确的结论是：创新需要与最终输出具有可验证的有效路径；不能让它只改善训练辅助指标，再期待一个表达范围受限的成员加权器自动兑现全部类别收益。
