# 首块证据直通从头训练复验

本轮检验首块证据与末层读出从随机初值共同学习时，能否降低噪声引起的第二目标误报，同时保持真实双目标的识别。只运行训练种子 13。已有 SE-F-13 的训练和六档评价直接复用。

| 实验 | 公共判别路径 |
| --- | --- |
| SE-F-13 | 原模型，无额外残差 |
| SE-B-13 | 将末层表示送入投影，并加回末层 |
| SE-C-13 | 将首块表示送入同规格投影，并加到末层 |

B 与 C 都增加 32,768 个参数。两层无偏置投影为 256 → 64 → 256，中间用 GELU，末层矩阵初始化为零。两组的公共网络和新增参数均接受完整训练，统一使用正式配置的学习率。初始化短测对照新构造的 F，验证三组共享参数和初始输出一致、B／C 投影初值一致、投影能更新、重载后下一步更新一致。训练入口不读取已训练的 F／V1／P50 参数。 [初值与重载检查](./runs/evidence_smoke.json)

数据划分、固定双散射、Train 原始归一化、波形存储视图、训练抽样 50／10／10／10／10／10、评价噪声种子和原任务损失均沿用 SE-F-13。AdamW 学习率 3e-4，最少 40 轮、最多 80 轮、耐心 10 轮，主分累计刷新 0.2 个百分点时更新早停时钟。种子 42 留到结构和训练日程确定之后。 [原正式配置](./正式实验配置.json)

## 选轮与评价

权重按统一的六档 Val 排序封存，依次比较六档 Single／Double 平衡分、六档综合均值、较弱数量组的六档均值和原始综合。架构复验重点读 5／0／−5／−10 dB 的 Single、Double、综合 ACC 和数量误判方向，连同原始、10 dB 和背景表现一起判断。5 dB Test 综合 ACC 80% 是阶段性能目标。正式预测保留七集合结果与逐录音指标。

同时比较 C 相对 F 和等参数 B 的变化，检查优势是否来自首块输入。封存后将两候选的新增投影关闭一次，记录任务成绩和误判变化。以 Val 的同源无第二类及加入弱第二类的配对视图检查指定第二类的误报和正确组合召回。诊断只用于解释机制，模型输入始终为当前观测波形。

本轮以确认 C 是否值得纳入最终结构为终点。C 未通过时，再执行单独的原结构训练日程对照。当前不并行启动分阶段训练或其他候选。
