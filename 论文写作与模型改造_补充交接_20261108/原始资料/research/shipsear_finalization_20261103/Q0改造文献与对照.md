# Q0 首块交互的改造依据

2026-11-04。Q0 保留两路固定散射、TabM 的 32 成员和七集合直接读出。5 dB Test 综合为 79.13%，在相同 877 条样本上还需净增 8 条正确才能超过 80%。0 dB 的 Single 已反超 Double，继续以实际单双目标错误和六档结果评价。 [Q0 完整训练报告](./公共判别接口完整训练报告.md)

## 可以借鉴的机制

1. **双线性乘积的幂归一化。** Yu 等的 MFB 在低秩因子逐元素相乘并分组求和后，对融合向量做带符号平方根和 L2 归一化。作者将其用于抑制乘积后的坐标幅度差异，并在视觉问答上检验了两个归一化步骤。Q0 的 64 维乘积与其有相似的幅度问题，但这里没有分组求和，且交互量通过残差进入已有直通路径，适合先单独检验保留整体尺度的坐标重分配。 [Yu 等，ICCV 2017，第 3 节与第 4.3 节](https://openaccess.thecvf.com/content_ICCV_2017/papers/Yu_Multi-Modal_Factorized_Bilinear_ICCV_2017_paper.pdf)
2. **保留直通与交互残差。** Kim 等的 MRN 用线性捷径配合两路非线性投影相乘形成联合残差，并比较了不同捷径和交互设计。这个先例支持把直通和跨路项分开检验。Q0 的直通层已接收两路拼接特征，I0 对照也显示移除整条交互支路会增加 5／0 dB 组合错判。 [Kim 等，NeurIPS 2016，第 3 节与第 4.2 节](https://proceedings.neurips.cc/paper_files/paper/2016/file/9b04d152845ec0a378394003c96da594-Paper.pdf) · [I0 完整结果](./公共判别接口完整训练报告.md)
3. **保留成员平均作为受控基线。** TabM 原论文把成员权重共享和多成员预测的平均作为核心机制，在其表格数据上分析了成员平均的收益。Q0 已使用此机制，当前证据集中在首块的两路乘积，可以先固定成员数和集成方式。 [Gorishniy 等，ICLR 2025，第 3 节与第 5.2 节](https://proceedings.iclr.cc/paper_files/paper/2025/file/c1ba41c694834aeef91ae161711d4939-Paper-Conference.pdf)

## 候选与判定

封存 Q0 的 Val 回放中，原始／5／0 dB 的 64 维乘积里幅值最大四个坐标的能量占比中位数为 61.37%／66.83%／65.99%，门控后的交互与直通 RMS 比值中位数为 0.337／0.475／0.532。集中现象也存在于预测正确的样本，因而只是候选动机。待检验的假设是，降低交互坐标的集中程度后，弱一些的组合证据能在同一份双路输入下发挥作用。 [Q0 首块代码](../shipsear_final_noise_distribution_20261102/model.py#L38)

只训练一个候选。设每个成员的乘积为 $t=u\odot v$，在投影前用稳定化带符号平方根 $r=t/\sqrt{|t|+\varepsilon}$，再计算 $\tilde t=r\,\mathrm{RMS}(t)/\max(\mathrm{RMS}(r),\varepsilon)$。该变换在有效幅度下保留输入乘积的 RMS，压低少数大坐标相对其余坐标的幅度，全零输入输出仍为零。投影和门控内与乘积有关的统计都读取同一份 $\tilde t$，两路单独的统计继续使用 $u,v$。这是基于 MFB 幂归一化的本地适配，恢复原 RMS 是为隔离坐标重分配与整体缩放而设。首块以外的 Q0 结构和训练协议作为对照条件。

按种子 13 从头训练，复用 Q0 对照。沿用六档 Val 综合选轮，封存后报告完整 Test。记录各档乘积能量集中度与 RMS 比，确认变换实际到位，并检查经过投影及门控后交互与直通的实际强度比。性能上优先看 5 dB 净增正确数及 Double 组合错判，再核对 0 dB 双向数量误判、原始和 10 dB 目标、Single 严格领先的档数。能量分布变化本身是实现核对。若后续需要区分乘积与加法、样本门控与全局标量，各自使用已登记的 A0、G0 对照。 [统一收尾路线](./统一收尾路线.md)
