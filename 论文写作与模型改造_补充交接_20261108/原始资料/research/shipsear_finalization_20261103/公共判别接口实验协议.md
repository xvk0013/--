# 公共判别接口对照

2026-11-04。固定现有一维波形散射和长短窗二维谱散射，区分首块跨路交互与末端数量偏移对完整七集合识别的作用。

| 实验 | 结构 |
| --- | --- |
| SE-F-13 | 复用已封存的完整模型 |
| SE-I0-13 | 首块恢复原版 TabM 的直通层，去掉乘积交互与门控，保留数量联合读出 |
| SE-Q0-13 | 保留首块交互，移除数量分数的加法支路，由七集合概率求和计算数量辅助损失 |

两组从相同种子 13 的随机初值训练。模型保留部分的初始参数与 F 一致。短测检查移除的参数、初始 logits、训练更新和恢复后的下一步。沿用 Train 原始特征标准化、Single／Double／背景损失预算 30／60／10、七集合交叉熵与 0.1 倍数量边际损失、原始 50% 和五档加噪各 10%、六档 Val 排序与早停。两组完成 Val 封存后统一评估 Test。 [正式协议](./正式实验协议.md)

比较六档综合和分组准确率、5／0 dB 的双向数量误判和 Double 组合错判，以及相对 F 的逐样本纠正与损坏。采用时核对原始门槛、10／5 dB 的 80% 目标和多数档 Single 严格优于 Double。0 dB 单独报告表现。错误方向按同一组样本的合法集合预测计算。
