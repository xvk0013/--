# 类别分组成分编码／深度展开：机制研究审查

日期：2026-10-26。只审查，不训练、不改模型。目标是让中间成分表示对集合识别承担实际职责，并检验这种职责是否有分类价值。

## 1. 一手依据与已有重合

[Parekh等，TASLP2024](https://arxiv.org/html/2305.07132)以预学习NMF字典、神经隐藏层预测时间激活、重建及稀疏约束建立可听解释，并区分事后解释与由解释分支直接分类。尤其IV-B3已针对SONYC-UST先学习背景噪声字典，再固定背景、按类别正样本学习类别字典。因此“按类分组＋背景组＋NMF重建＋稀疏＋神经激活”已有明确近邻，不能整体换名后作为新的核心。

[Tanji与Murakami，IEICE2023](https://www.jstage.jst.go.jp/article/transfun/E106.A/7/E106.A_2022EAP1098/_article)研究神经化乘法更新及可解释散度设计，并用于音频去噪和监督分离。有限层更新、非负激活及学习更新规则有方法基础；若任意MLP代替更新、没有优化目标对应，不宜声称得到有明确算法意义的深度展开。本轮核对其出版方摘要，未逐式复现全文。

**可研究的具体增量：用可追溯真实录音成分监督锚定类别组，让这些组直接产生集合判别证据，并针对背景吸收弱目标的风险设计约束。** 这仍是候选，需要超过同监督的普通模块与普通分组NMF。

## 2. 使解释变量进入真实决策

建议接口为：非负线性谱Y＋M2局部特征F→非负初始激活H⁰→有限次成分更新→PF／MB／RV及背景残余的成分估计→三个类别证据→原七集合评分的直接修正。旧成员选择器被替换；散射TabM保留为原始证据与强参照。M2只负责初始估计，不把深特征当作严格可相加的物理成分。

可写Y≈Σc DcHc＋DnHn，但幅度／功率谱相加是模型近似。功率谱含交叉项，不能声称它等于两源功率之和；对数Mel更不能以同样公式冒充物理守恒。固定字典列范数，消除D增大、H缩小而虚假降低稀疏惩罚的尺度自由度。

三个类别修正应由对应组激活／成分经过小型受限读出得到。不能让分类头主要读取原始F、重建误差或旧TabM旁路，而成分仅作画图。保留原强参照是公平比较；候选中移除重复旧选择职责是为了使新机制可检验。

## 3. 源监督如何锚定语义

- 仅使用Train索引中可重建的传播后源成分，按实际source增益、包络和输入标准化增益计算各类别目标谱。某类缺席时该组目标为零；混合内多段同类可求和，但不把类别数等同物理声源数。
- 可以直接监督每个组的重建成分与相应源成分谱，或监督由源谱构造的比例掩码。后者需明确是比例目标，不是混合功率的物理精确分解。识别／数量监督保持真实任务标签。
- 原始船声录音本身含自然背景；类别目标是该录音成分，不能称已得到纯净船舶声。已知追加AWGN可作背景监督；不能把从船声中未经标注的残余硬称环境真值。
- 推理只输入混合波形及其F、Y和TabM输出。源波形、真实类别、真实数量及真实SNR不得用于选择字典组或掩码；所有组同时计算。

## 4. 防止“重建更好、识别无益”与背景吞噬

重建损失不能单独验收。类组须同时接受类别存在／集合识别监督，并检查移除某组后该类相关集合的相对证据是否有对应变化；最终仍看Single／Double互判、条件船型错误与完整ACC。若新修正权重趋于零、组置零不改变输出，就记录该模块未承担识别职责，不能强制打开权重制造“作用”。

背景字典优先从Train背景和已知噪声学习并限制自由度；类别组使用真实源成分监督，防止背景组任意拟合全部目标。检查弱目标能量／存在证据被分给背景的比例，以及不含该类时的伪激活。全局L1或强组稀疏可能优先删除弱RV，不应只用更高稀疏度作成功指标。新背景组的容量应与普通NMF对照相同。

## 5. 少量源录音的主要限制

RV仅3条Train来源时，字典可能学会这些录音的谱指纹。按源录音均衡贡献、限制每类字典规模，并用现有Val来源检查类别组能否重建／识别未见录音；不能靠同源片段重建优秀宣称跨录音语义。对Bellhop／噪声变化的稳定性只能证明相应受控因素，不等于船舶个体泛化。没有必要因此重排Test录音。

## 6. 最小公平对照

|对照|回答的问题|
|---|---|
|同输入普通MLP／卷积成分预测器|相同F、Y及源监督下，结构约束是否超出普通网络；应提供同样辅助成分监督，避免把额外标签收益归给展开|
|普通监督分组NMF＋同一读出|类别字典与源锚定本身能做到什么，展开是否有独立价值|
|同容量展开、无类别组锚定|一般可重建成分是否足够，类别语义锚定是否必要；保持训练来源数量一致|
|拟议类别锚定展开|组合机制的完整效果；对比前三项，并与原强系统单独列示|

这四项是方法筛选，不需要现在将全部损失与背景配置排列组合。若收益只来自源监督、普通预测器同样有效，就将结果归为监督收益；若普通分组NMF相同，就不宣称展开带来优势。核心需要同时体现组语义、实际决策作用及对应识别价值，不能仅靠重建图或较新的模块名称。
