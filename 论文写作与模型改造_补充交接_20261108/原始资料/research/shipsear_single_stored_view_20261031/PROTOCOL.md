# 含噪Single训练视图修订：同起点对照

本轮检验：将Single的训练波形与正常评价波形对齐，能否提高5／0dB Single，并保住Double及原始综合能力。仅训练一个新候选，完成后自动生成报告；不持续人工跟踪训练，不自动追加实验。

## 唯一训练变化

| 对象 | C1均匀覆盖对照 | V1存储Single候选 |
| --- | --- | --- |
| 原始Single | 正式存储波形 | 相同 |
| 10／5／0dB Single | 既有人工包络后追加AWGN | 正式存储波形直接追加AWGN |
| −5／−10dB Single | 正式存储波形后追加AWGN | 相同 |
| Double与背景 | 原数据与原加噪规则 | 相同 |

人工包络指渐入、渐出或中间突出等幅度曲线，随后恢复整段RMS。它属于训练增强，但也改变局部能量与局部SNR。本轮不更改标签、录音划分或目标组合，不将存储Single替换为额外来源音频。

此前固定模型诊断中的85.88%与71.06%，是Train Single包络／存储波形的0dB配对成绩，不是两份模型的Test性能。该诊断只输入Single，Double没有参与配对，所以当时Double不变。本轮会真正训练公共网络，并重新评价Single、Double及背景。

## 起点、模型与预算

- C1与V1均从原F1M1第33轮开始，使用完全相同的已训练公共权重及原始Train特征归一化。
- C1复用`shipsear_f1m1_snr_balance_20261031/runs/seed13`中完整20轮历史及封存权重。用本轮相同Val保护与排序重放旧历史，确认复用选择仍然一致；不在Test上另选轮次。
- V1保持固定一维散射3730维、长短窗二维谱散射3200维及原公共TabM。没有新增局部参照算子、GRU、专家或分类头。
- 固定小波核与谱变换，公共TabM、成员交互、门控、集合输出及数量残差全部继续训练。Double数据不变不等于其最终性能必然不变，完整模型会统一评价。
- 原录音级Train／Val／Test划分及2880／716／877条样本固定，不重新生成数据集，不移动录音。
- 训练SNR概率固定：原始50%，10／5／0／−5／−10dB各10%；各类别使用同一规则，不强制每轮精确配额。
- 种子13；沿用C1相同样本次序、源epoch34至53的逐轮噪声方向与公共dropout随机流。噪声功率与RMS处理不变。
- 同样新建AdamW，公共与数量读出学习率3e−5，weight decay1e−4，梯度裁剪5。完整续训20轮，不提前停止。
- 保留原类别损失预算、七集合交叉熵＋0.1数量边缘监督，不同时改损失或数量判别规则。

这是沿用既有训练历史的同起点适配对照，不称为随机初始化的结构比较。

## Val选择与原始Single余量

每轮记录六档Val，保护与排序在训练前固定：

1. 原始Single相对源F1M1 Val允许下降5个百分点；原始综合最多下降1.5个百分点。
2. 原始Double／背景及10dB综合，相对源模型最多下降1个百分点。
3. 5／0dB Double分别同时相对源F1M1与C1保护1个百分点。
4. 先按是否全部满足保护排序，再按5／0dB平均综合、平均Single、原始综合排序。
5. 仅选择第1至20轮实际训练权重，第0轮只作参照；负SNR监测但不参与排序。

没有完全满足保护的轮次时，仍报告实际最佳训练权重和未通过项，原模型单独保留。权重按Val封存后统一评价六档Test，同一份权重用于全部SNR。

预设有意义增益条件为：通过上述Val保护，且0／5dB平均Val Single相对C1至少提高2个百分点、平均综合至少提高1个百分点。该门槛用于候选判断，不将本次训练视图修订本身包装为网络结构创新。

用户允许原始Single适度回落。约87%的原始Single仅用于说明在当前Test构成、Double与背景不变时维持综合85%以上的余量，不是Test选模阈值。修订的目标是增加5／0dB的实际正确识别，而不只是降低原始起点使曲线看起来变缓。
