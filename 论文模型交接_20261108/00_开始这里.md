## 在解压目录运行推理

输入准备为 5 秒、16 kHz 的单通道波形数组 `waveforms.npy`，形状为 `(N, 80000)`。以下各行从包含本 README 的目录运行。

```powershell
python -B "01_ShipsEar_Q0/predict.py" --input "waveforms.npy" --output "shipsear_q0.npz" --device cpu
python -B "02_ShipsEar_ShortLocal_GN/predict.py" --input "waveforms.npy" --output "shipsear_gn.npz" --device cpu
python -B "03_DeepShip_PTT_Q0/01_模型/Q0_DeepShip/predict.py" --checkpoint "03_DeepShip_PTT_Q0/01_模型/Q0_DeepShip/runs/DS-Q0-PTT-SeenShip-13/best.pt" --input "waveforms.npy" --output "deepship_ptt_q0.npz" --device cpu
```

输出为 `probabilities`、`predictions`、`counts` 和 `sets`。需要 CUDA 时将 `--device cpu` 换为 `--device cuda`。已核对 Python 3.10、NumPy 2.1.2、PyTorch 2.9.0、SciPy 1.15.3、packaging 25.0、typing-extensions 4.15.0。GN 还需要与 PyTorch 版本和构建匹配的 torchaudio 2.9.0。阅读源码、图和已封存成绩只需解压。
